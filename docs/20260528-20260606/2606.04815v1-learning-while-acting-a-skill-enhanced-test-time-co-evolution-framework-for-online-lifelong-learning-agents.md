## 摘要
终身学习对于在动态、交互环境中运行的大型语言模型（LLM）智能体至关重要。然而，现有的面向长周期任务的终身学习智能体通常依赖于推理过程中静态参数的离散技能或过去经验检索，这阻碍了它们像人类学习者那样持续内化测试时的反馈。为弥补这一差距，我们提出了技能增强测试时协同进化（\texttt{LifeSkill}），这是一个面向在线终身学习智能体的两阶段强化学习框架。具体而言，我们设计了验证器引导的技能学习，它通过根据多个技能条件策略推演的平均验证器成功率对候选技能进行奖励，从而解决了技能提取缺乏直接监督的问题，鼓励模型生成有助于解决任务而非仅在文本上合理的技能。此外，我们引入了在线技能内化，通过在测试时交互过程中将技能条件轨迹转化为奖励信号，持续改进策略模型。这使得智能体能够将推理能力直接内化到其参数中，避免了经验检索的上下文膨胀。在LifelongAgentBench上的实验表明，与现有终身智能体基线相比，LifeSkill的平均性能提升了7个绝对百分点。

## Abstract
Lifelong learning is essential for Large Language Model (LLM) agents operating in dynamic, interactive environments. However, existing lifelong learning agents for long-horizon tasks typically depend on discrete skill or past experiences retrieval with static parameters during inference, which prevents them from continuously internalizing test-time feedback like human learners. To bridge this gap, we propose Skill-enhanced Test-Time Co-Evolution (\texttt{LifeSkill}), a two-stage reinforcement learning framework for Online Lifelong Learning Agents. Specifically, we design Verifier-Guided Skill Learning that addresses the lack of direct supervision for skill extraction by rewarding candidate skills according to the average verifier success of multiple skill-conditioned policy rollouts, encouraging the model to generate skills that are useful for solving tasks rather than merely plausible in text. Furthermore, we introduce Online Skill Internalization, which continuously improves the policy model during test-time interaction by transforming skill-conditioned trajectories into reward signals. This enables the agent to directly internalize reasoning capabilities into its parameters, avoiding the context bloat of experience retrieval. Experiments on LifelongAgentBench show that LifeSkill improves average performance by 7 absolute points by comparing with existing lifelong agent baselines.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的大语言模型（LLM）智能体在动态、交互环境中进行长周期任务时，通常依赖**静态参数**和**外部记忆检索**（如经验回放、技能库），无法像人类学习者那样在测试时持续内化反馈，实现真正的终身学习。
- **三个关键局限**：
  1. 部署期间模型参数固定，无法真正学习；
  2. 从交互反馈中提取可复用技能缺乏可靠的执行接地监督；
  3. 获得的知识通常以外部文本形式存在，难以内化为参数化能力，导致组合和泛化困难。
- **研究背景**：终身学习是LLM智能体在动态环境中不可或缺的能力，但现有方法（如基于记忆的经验重用、测试时自我改进）仍停留在检索-推理范式，未能实现持续的适应性增长。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：通过强化学习同时改进技能提取和技能内化，形成**测试时协同进化循环**：更好的技能提取→更有效的探索→更强的策略参数→更优的轨迹用于后续技能学习。

- **两阶段框架（LifeSkill）**：
  - **阶段一：Verifier-Guided Skill Learning（VGSL，验证器引导的技能学习）**
    - 针对失败的初始尝试，技能提取模型 $\pi_\phi$ 采样 $K_s$ 个候选技能 $s_i$。
    - 对每个技能，策略模型 $\pi_\theta$ 执行 $K_\tau$ 次技能条件推演，获得验证器奖励 $r_{i,j}$。
    - 定义技能效用 $R_i = \frac{1}{K_\tau}\sum_j r_{i,j}$，并计算归一化相对优势 $\hat{A}_i$。
    - 使用DAPO token级裁剪目标优化 $\pi_\phi$，使提取的技能改善执行而非仅仅文本合理。
  - **阶段二：Online Skill Internalization（OSI，在线技能内化）**
    - 从成功的技能条件轨迹中移除技能文本，仅保留原始任务输入和轨迹 $(q, \tau)$。
    - 重新计算当前策略在原始输入下的轨迹对数似然 $\log \pi_\theta(\tau | q)$。
    - 使用奖励加权策略优化更新 $\pi_\theta$：$\mathcal{L}_{\text{OSI}} = -\frac{1}{|B_t|} \sum_{(q,s,\tau,r) \in B_t} r \log \pi_\theta(\tau | q)$，仅成功的轨迹提供学习信号。

- **整体流程**：任务流按窗口处理，每个窗口内先由策略模型尝试原始输入，失败后提取技能并进行技能条件重试；收集的所有交互数据用于在线更新两个模型，之后再处理下一窗口。

## 6. 主要结论与发现

- LifeSkill在三个环境上的**平均准确率0.59**，比最强基线（RFT的0.52）**提升7个绝对百分点**；在DB和OS上达到最佳（0.82和0.64）。

- 技能提取质量随训练**逐步提升**：早期技能较通用，后期技能更精确、与任务语义对齐，能直接修正策略错误。

## 7. 优点

- **双模型协同进化**：创新性地将技能提取和策略内化作为耦合的RL过程，实现了持续在线适应。
- **执行接地监督**：使用任务验证器的成功信号（可验证、确定性）而非主观LLM评判，使技能学习更面向实际执行效果。
- **在线参数内化**：提出在测试时直接更新策略参数，将探索发现的能力永久吸收，无需外部记忆。
- **实验详细，透明度高**：包含消融、超参数分析、定性案例，有助于理解方法行为。

- **未讨论遗忘问题**：在线持续更新可能面临灾难性遗忘，论文未分析或引入防遗忘机制。
- **评估数据集单一**：仅使用LifelongAgentBench，缺乏更多样化的终身学习场景（如机器人控制、网页导航）的验证。
