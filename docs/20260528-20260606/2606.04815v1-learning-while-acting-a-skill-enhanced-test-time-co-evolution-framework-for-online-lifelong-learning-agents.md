## 摘要
终身学习对于在动态、交互环境中运行的大型语言模型（LLM）智能体至关重要。然而，现有的面向长周期任务的终身学习智能体通常依赖离散技能或过去经验的检索，并在推理时使用静态参数，这阻碍了它们像人类学习者一样持续内化测试时反馈。为弥补这一差距，我们提出了技能增强的测试时协同进化（LifeSkill），这是一个面向在线终身学习智能体的两阶段强化学习框架。具体来说，我们设计了验证器引导的技能学习，通过根据多个技能条件策略 rollout 的平均验证器成功率为候选技能赋予奖励，从而解决技能提取缺乏直接监督的问题，鼓励模型生成有助于解决任务的技能，而不仅仅是文本上合理的技能。此外，我们引入了在线技能内化，通过在测试时交互过程中将技能条件轨迹转化为奖励信号，持续改进策略模型。这使得智能体能够将推理能力直接内化到其参数中，避免了经验检索带来的上下文膨胀。在LifelongAgentBench上的实验表明，与现有终身智能体基线相比，LifeSkill的平均性能提升了7个绝对百分点。

## Abstract
Lifelong learning is essential for Large Language Model (LLM) agents operating in dynamic, interactive environments. However, existing lifelong learning agents for long-horizon tasks typically depend on discrete skill or past experiences retrieval with static parameters during inference, which prevents them from continuously internalizing test-time feedback like human learners. To bridge this gap, we propose Skill-enhanced Test-Time Co-Evolution (\texttt{LifeSkill}), a two-stage reinforcement learning framework for Online Lifelong Learning Agents. Specifically, we design Verifier-Guided Skill Learning that addresses the lack of direct supervision for skill extraction by rewarding candidate skills according to the average verifier success of multiple skill-conditioned policy rollouts, encouraging the model to generate skills that are useful for solving tasks rather than merely plausible in text. Furthermore, we introduce Online Skill Internalization, which continuously improves the policy model during test-time interaction by transforming skill-conditioned trajectories into reward signals. This enables the agent to directly internalize reasoning capabilities into its parameters, avoiding the context bloat of experience retrieval. Experiments on LifelongAgentBench show that LifeSkill improves average performance by 7 absolute points by comparing with existing lifelong agent baselines.

- **研究动机**：大型语言模型（LLM）智能体在动态、交互环境中需要具备终身学习能力，即持续从交互经验中积累知识并提升能力。然而，现有终身学习智能体在推理时通常保持模型参数固定，依赖外部记忆（如轨迹检索、技能库）来改善性能，无法像人类学习者一样将测试时反馈内化为持久的参数化能力。
- **关键挑战**：
  - 模型参数在部署时固定，不能真正从交互中学习。
  - 如何从失败交互中提取可复用的技能缺乏执行层面的可靠监督（通常依赖LLM评判器，主观且与任务成功间接相关）。
  - 习得的知识通常存储为外部文本，难以内化、组合和泛化，导致推理时上下文不断膨胀。

## 2. 方法论：核心思想与技术细节

- **整体框架**：LifeSkill 是一种两阶段强化学习框架，包含两个模型：策略模型 πθ（执行任务）和技能提取模型 πϕ（从失败交互中提取技能）。两者通过测试时在线协同进化。
- **阶段一：验证器引导的技能学习（Verifier-Guided Skill Learning, VGSL）**
  - 当初始策略尝试失败后，技能提取模型采样 Ks 个候选技能文本。
  - 对每个技能 si，策略模型采样 Kτ 条技能条件轨迹，并获取任务验证器（deterministic binary verifier）的成功率 Ri。
  - 将 Ri 归一化为相对优势 Âi，使用 DAPO 目标（token-level clipped objective）更新技能提取模型，激励其生成能提高下游执行成功率的技能。
- **阶段二：在线技能内化（Online Skill Internalization, OSI）**
  - 收集窗口内的所有技能条件轨迹（包括 VGSL 使用的 rollout），去除输入中的技能文本，仅保留原始任务输入和轨迹。
  - 重新计算轨迹在无技能条件下（仅原始任务输入）的对数概率，并使用对应验证器奖励（1表示成功）进行加权策略优化（reward-weighted policy optimization）。
  - 公式：LOSI(θ) = - (1/|Bt|) Σ_{(q,s,τ,r)∈Bt} r log πθ(τ | q)，仅成功轨迹贡献梯度。
- **协同进化循环**：VGSL 提升技能质量，OSI 将成功探索行为内化到策略参数中，两者交替更新，无需外部记忆检索。

## 6. 主要结论与发现

- LifeSkill 在 LifelongAgentBench 上平均准确率达到 0.59，超越最强训练无关基线（Group Self-Consistency，0.49）10个绝对点，超越最强训练基线（RFT，0.52）7个绝对点。
- 在 DB 和 OS 环境上取得最高分，但在 KG 上未超越训练无关基线（0.32 vs 0.36），归因于KG轨迹更长、奖励更稀疏。
- 消融实验表明，验证器引导的技能学习比LLM评判更有效；技能提取模型和在线内化均显著贡献性能。

- 定性分析显示，提取的技能随训练过程逐步精确，并能纠正策略的语义理解错误。
