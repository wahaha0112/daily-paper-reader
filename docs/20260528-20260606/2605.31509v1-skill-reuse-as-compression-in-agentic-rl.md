## 摘要
使用强化学习训练的大型语言模型智能体通常学会脆弱、特定任务的捷径。我们假设，当智能体的成功轨迹在结构上可压缩，分解为一小组可重用的抽象模式时，它们能更好地泛化。为了形式化这一点，我们引入了ReuseRL，它将智能体强化学习建立在最小描述长度（MDL）原则之上。ReuseRL从成功轨迹中提取共享的技能字典，并通过分割成本增强强化学习目标，明确惩罚编码效果差的特殊行为。我们证明了该压缩惩罚的PAC-Bayes泛化界。在ALFWorld、TextWorld-Cooking和Countdown-Stepwise上，ReuseRL在分布内和分布外的成功率均优于原始GRPO和强回合长度基线。

## Abstract
Large language model agents trained with reinforcement learning (RL) often learn brittle, task-specific shortcuts. We hypothesize that agents generalize better when their successful trajectories are structurally compressible, decomposed into a small set of reusable abstract patterns. To formalize this, we introduce ReuseRL, which grounds agentic RL in the Minimum Description Length (MDL) principle. ReuseRL extracts a shared skill dictionary from successful trajectories and augments the RL objective with a segmentation cost, explicitly penalizing idiosyncratic behaviors that encode poorly. We prove a PAC-Bayes generalization bound for this compression penalty. Across ALFWorld, TextWorld-Cooking, and Countdown-Stepwise, ReuseRL improves in- and out-of-distribution success over vanilla GRPO and strong round-length baselines.

## 2. 方法论：核心思想、关键技术、算法流程

### 核心思想
- 成功的行为序列应能被**少量共享的短语（技能）** 高效编码，而非依赖的一次性特殊模式。纯净的“只压缩长度”不足以区分可重用与偶然结构，必须奖励**结构化的压缩**。

### 关键技术
- **技能投影（Skill Projection）**：将原始动作序列通过规则映射为原子技能序列（如 EXPLORE、TAKE 等），形成符号序列 s。
- **技能字典（Skill Dictionary）**：一个短语集合 C，其中每个短语是至多 L 个原子技能的短序列。字典包含所有单例技能以保证总能编码。
- **分割成本（Segmentation Cost）**：给定字典 C，一条技能序列 s 的最小短语分割数记为 seg(s, C)。归一化分割成本 SegCost(s|C) = seg(s, C)/T。
- **MDL 目标（两段编码）**：对当前成功批次 B⁺，最小化两项之和：
  - 字典存储成本 L_skill_dict(C)（共享，平分到每条轨迹）
  - 用字典短语编码成功序列的成本（seg(s, C) log₂|C|）
- **EM 式交替优化**：
  - **E 步**：从当前成功批次（结合全局 FIFO 缓存）中，通过贪心 BPE 合并最小化批次级 MDL 目标，提取字典 Ĉ。
  - **M 步**：固定 Ĉ，用 GRPO 更新策略，对成功轨迹附加分割成本惩罚：`R(τ) − λ·1{success}·SegCost(s|Ĉ)`。惩罚只作用于成功轨迹，不打击任务完成。
- **理论贡献**：证明纯回合长度惩罚是固定码退化的分割成本（Proposition 1）；推导 PAC-Bayes 泛化界（Theorem 3），表明 MDL 目标能控制未来成功轨迹的期望描述长度。

### 算法流程（文字说明）
1. 用当前策略在任务分布上采样一批轨迹。
2. 筛选出成功轨迹 B⁺，提取其技能序列。
3. （可选）将成功序列加入全局 FIFO 缓存。
4. 对 B⁺ ∪ 缓存进行贪心 BPE 合并，接受严格降低批量 MDL 目标的合并，得到字典 C。
5. 对每条成功轨迹计算分割成本 SegCost，构造整形奖励。
6. 用 GRPO 更新策略，优化包含分割成本惩罚的目标。
7. 重复。

## 6. 主要结论与发现

1. **结构压缩提升泛化**：ReuseRL 在所有基准上的分布内和分布外成功率都超过 GRPO 和纯长度惩罚。
2. **纯长度惩罚的反面案例**：在 TextWorld-Cooking 中纯长度惩罚反而严重退化（准确率低于 GRPO），因为它盲目缩短步骤却导致“烧焦”失败；而结构压缩保持了可重用子程序。
3. **全局缓存的双刃剑**：在 Countdown 和 ALFWorld 上缓冲有益，但在 TW-Cooking 简单任务主导时可能稀释困难样例的稀有结构，移除缓存反而提升。
4. **压缩成功的轨迹优于压制所有步骤**：ReuseRL 在可逆和不可逆动作环境下均稳健，证明基于字典的结构压缩是信息丰富的正向信号。

## 7. 优点

- **理论坚实**：将泛化与 MDL 原则建立直接联系，提供 PAC-Bayes 收敛保证，并统一了先前方法（SkillRL、ERL）作为隐式部分 MDL 最小化。

- **消融设计清晰**：通过纯长度惩罚对比证明了“结构”相对“长度”的额外价值；通过全局缓存消融展示了缓冲适应的环境敏感性。
