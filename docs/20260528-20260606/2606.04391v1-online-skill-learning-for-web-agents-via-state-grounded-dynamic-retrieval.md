## 摘要
语言代理越来越依赖可复用技能来改进跨相关任务的多步Web自动化。越来越多的研究关注在线技能学习，其中代理不断从之前的任务轨迹中归纳技能，并在将来任务中即时复用。然而，现有方法主要在任务层面复用技能：根据初始任务指令检索一组固定技能，并在整个执行过程中保持不变。这种静态策略与Web执行不一致，因为适当的下一步行动不仅取决于任务目标，还取决于当前网页状态，而网页状态经常转变为初始技能无法覆盖的情况。为解决这一差距，我们提出状态基础动态检索（SGDR），一种在线技能学习方法，使Web代理能够逐步复用技能。SGDR包含三个组件：滑动窗口提取过程，将完成的轨迹转化为可在中间执行状态调用的可复用子程序；双文本-代码表示，将技能检索与可执行动作连接；以及状态基础动态检索机制，将技能与任务目标和当前网页状态相匹配。在跨五个领域的WebArena上的实验表明，SGDR持续优于强基线，使用GPT-4.1平均成功率达到37.5%，使用Qwen3-4B达到24.3%，分别相对于最强基线有10.6%和10.0%的相对提升。代码可在https://github.com/plusnli/skill-dynamic-retrieval获取。

## Abstract
Language agents increasingly rely on reusable skills to improve multi-step web automation across related tasks. A growing line of work studies online skill learning, where agents continually induce skills from previous task trajectories and reuse them in future tasks on the fly. However, existing methods mainly reuse skills at the task-level: a fixed set of skills is retrieved based on the initial task instruction and then held fixed throughout execution. This static strategy is misaligned with web execution, where the appropriate next action depends not only on the task goal but also on the current webpage state, which often transitions into situations that the initial skills fail to cover. To address this gap, we propose State-Grounded Dynamic Retrieval (SGDR), an online skill learning method that enables stepwise skill reuse for web agents. SGDR consists of three components: a sliding-window extraction process that turns completed trajectories into reusable sub-procedures invokable at intermediate execution states, a dual text-code representation that connects skill retrieval with executable action, and a state-grounded dynamic retrieval mechanism that matches skills to both the task goal and the current webpage state. Experiments on WebArena across five domains show that SGDR consistently outperforms strong baselines, achieving average success rates of 37.5% with GPT-4.1 and 24.3% with Qwen3-4B, corresponding to relative gains of 10.6% and 10.0% over the strongest baseline, respectively. The code is available at https://github.com/plusnli/skill-dynamic-retrieval.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究问题**：现有在线技能学习方法（如 AWM、ASI、CER）在执行多步 Web 任务时，只在任务开始时根据初始指令检索一组固定技能，并在整个执行过程中保持不变。然而，Web 执行中网页状态（如页面、表单、菜单）会动态变化，导致初始技能可能变得不相关，而其他未选中的技能反而在后续状态中有用。这种**任务级静态复用**与交互式 Web 自动化不匹配。
- **整体意义**：为了提升 Web 代理的跨任务泛化能力和执行效率，需要实现**步骤级、状态感知的技能动态检索**，使技能复用在适当的中间状态而非仅在任务开头。

## 2. 方法论

- **核心思想**：将技能复用从任务级提升到步骤级，通过提取细粒度子过程并基于当前网页状态和任务目标动态检索，实现自适应技能支持。
- **关键技术细节**：
  - **技能提取**（Sliding-Window Extraction）：
    - 仅在评价器判定成功（ˆy=1）的轨迹上提取技能。
    - 对完整轨迹使用滑动窗口（窗口长度 L={2,3,4,5}）枚举子序列（o_t, a_t, ..., a_{t+l-1}, o_{t+l}）。
    - 用 LLM 判断每个子序列是否为可复用子过程，并生成对应的文本描述 d_k 和可执行代码 c_k（文本-代码对）。
    - 验证：将原始轨迹中对应动作段替换为技能调用后重新执行，仅保留仍被评价器判定成功的技能。
  - **技能表示**：双文本-代码对 s_k = (d_k, c_k)。描述用于检索，代码用于动作执行。
  - **状态接地动态检索**：
    - 每一步 t，先压缩当前网页状态 o_t 为简短摘要 r_t（使用 LLM）。
    - 计算每个技能 s_k 与当前任务指令 g 和状态摘要 r_t 的组合相关性分数：
      ```
      score_t(s_k) = α · cos(ϕ(g), ϕ(d_k)) + (1-α) · cos(ϕ(r_t), ϕ(d_k))
      ```
      α 为平衡超参数（默认为 0.5），ϕ 为文本嵌入函数。
    - 保留 top-M（M=20）候选技能。
    - 应用 **MMR（最大边际相关性）** 重排序，选择最终 5 个技能（|A_t|=5，λ=0.7）：
      ```
      MMR_t(s_k) = λ·score_t(s_k) - (1-λ)·max_{s_k'∈A_t} sim(d_k, d_k')
      ```
      sim 为描述间余弦相似度。
  - **技能注入**：将选择的 5 个技能的描述和代码提供给 agent，用于当前步骤决策；任务完成后，新技能加入领域特定技能库。

## 7. 优点

- **方法创新性**：首次在在线技能学习中实现状态感知的步骤级动态检索，解决了任务级静态复用的根本局限。
- **粒度平衡**：滑动窗口提取的2-5步子过程既保留了结构化的操作序列，又能在中间状态被调用，优于全轨迹或单动作。
- **表示设计**：文本-代码对将自然语言检索与可执行代码结合，简洁实用。
- **在线学习设置**：仅使用过去任务的经验，无作弊使用未来信息，贴近实际部署。
- **实验充分**：在两个骨干模型、五个域上验证，并进行了多组消融，结果一致性高。

## 8. 不足与局限
