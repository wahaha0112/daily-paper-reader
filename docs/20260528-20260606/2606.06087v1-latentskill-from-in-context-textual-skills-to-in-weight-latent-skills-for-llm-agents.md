## 摘要
智能体系统越来越多地使用文本技能来编码可重用的任务过程，但在每一步将这些技能注入提示中会带来巨大的上下文开销，并将技能内容暴露为明文。我们提出了LatentSkill，一个通过预训练超网络将文本技能转换为即插即用LoRA适配器的框架。LatentSkill将技能知识存储在权重空间而非上下文空间，移除每步的技能标记，同时保持模块化加载、缩放和组合。在ALFWorld和Search-QA上，LatentSkill优于对应的上下文技能基线，同时使用更少的预填充标记：在已见和未见分割上，ALFWorld成功率分别提升21.4和13.4个百分点，预填充标记减少64.1%；Search-QA精确匹配提升3.0个百分点，技能标记开销降低72.2%。进一步分析表明，生成的技能LoRA形成结构化的语义几何，可通过LoRA缩放系数精确控制，并且在技能组件对齐时可通过参数空间算术进行组合。这些发现表明，权重空间技能为扩展LLM智能体提供了高效、模块化且暴露更少的基质。

## Abstract
Agent systems increasingly use textual skills to encode reusable task procedures, but injecting these skills into the prompt at every step incurs substantial context overhead and exposes skill content as plaintext. We present LatentSkill, a framework that converts textual skills into plug-and-play LoRA adapters through a pretrained hypernetwork. LatentSkill stores skill knowledge in weight space rather than context space, removing per-step skill tokens while preserving modular loading, scaling, and composition. On ALFWorld and Search-QA, LatentSkill outperforms the corresponding in-context skill baseline while using substantially fewer prefill tokens: it improves ALFWorld success by 21.4 and 13.4 points on the seen and unseen splits with 64.1% fewer prefill tokens, and improves Search-QA exact match by 3.0 points with 72.2% lower skill-token overhead. Further analysis shows that generated skill LoRAs form a structured semantic geometry, can be precisely controlled via the LoRA scaling coefficient, and can be composed through parameter-space arithmetic when skill components are aligned. These findings suggest that weight-space skills provide an efficient, modular, and less exposed substrate for extending LLM agents.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：当前LLM智能体系统普遍采用将文本技能（textual skills）注入提示上下文（in-context）的方式，导致每步决策都需要重复插入技能文本，造成严重的上下文开销（prefill token数量剧增），并且技能内容以明文形式暴露，带来安全与隐私风险。同时，参数化替代方案（如微调）虽能避免上下文开销，但技能与模型参数永久融合，难以模块化更新、移除或组合。因此，存在一个“三难困境”：如何避免重复技能文本、保持技能模块化可更新、并支持推理时组合。
- **整体含义**：本文提出LatentSkill，将文本技能转换为LoRA适配器存储在权重空间而非上下文空间，实现零额外上下文标记、即插即用的模块化加载，并揭示权重空间技能具有结构化、可控性和可组合性。这是从“上下文技能”到“隐式技能”的范式转变，为高效、安全、灵活的LLM智能体扩展提供了新基质。

## 2. 方法论

- **核心思想**：通过一个预训练的**超网络（hypernetwork）**，将每个文本技能文档映射为一组LoRA更新权重（ΔW），这些权重直接添加到冻结的骨干LLM的特定层上，从而无需在提示中插入技能文本。
- **关键技术细节**：
  - **隐式技能定义**：设骨干LLM参数θ冻结，技能文档s，超网络Gϕ生成Δs = Gϕ(s)。推理时，将Δs挂载到模型：pθ,ϕ(y_t | h_t, s) = p_{θ ⊕ αΔs}(y_t | h_t)，其中α为注入系数，⊕表示LoRA参数增强。ΔW遵循标准LoRA形式：ΔW_s = B_s A_s。
  - **训练阶段**：
    1. **技能文档预训练（Skill Document Pretraining）**：在约17.1万GitHub技能文档（约3亿token）上预训练超网络。通过两个任务：重建任务（完整文档，模型生成原文）和补全任务（给定前缀生成后续）。目标函数为交叉熵，仅更新超网络参数。
    2. **轨迹监督微调（Trajectory-Supervised Fine-Tuning）**：使用教师代理轨迹数据（ALFWorld 237条、Search-QA 500条）进行微调。每个技能文档生成一个适配器，在同一轨迹所有步骤共享，目标函数鼓励适配器捕捉轨迹一致的策略信息，保持多步交互稳定性。
  - **推理时控制与组合**：
    - 单个技能：编译后缓存，挂载时乘以系数α，α=0恢复冻结模型，增大α增强技能影响。
    - 多技能组合：权重空间直接相加 Δ_K = Σ α_k C[k]。
    - 组件级组合：若技能可分解为语义组件，分别编译后选择性相加，避免共享组件重复放大。
