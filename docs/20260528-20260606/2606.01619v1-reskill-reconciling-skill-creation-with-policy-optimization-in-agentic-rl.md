## 摘要
智能体强化学习使大语言模型智能体能够从环境奖励中持续改进，但由此产生的策略并不会系统地积累可跨任务泛化的可复用策略。模块化技能可以提供这种可复用策略，然而现有的技能增强强化学习方法将技能创建与策略优化解耦，可能导致采用与不断演化的策略相冲突的技能。受Anthropic的Skill Creator启发，我们提出ReSkill，一种将技能演化与策略学习相协调的强化学习内循环技能创建框架。ReSkill利用GRPO的分组结构，仅需极小的额外开销即可自然地嵌入三种机制：（1）基于断言的技能创建器，从过往经验中诊断失败并提出基于条件的触发式技能修订；（2）组内轨迹采样，实现对技能版本的可控比较，捕捉哪个版本最能支持策略的持续学习；（3）采用自适应折扣的汤普森采样，在策略演化过程中平衡技能版本选择的探索与利用。在多个领域，ReSkill持续优于现有的记忆和基于技能的强化学习方法，在未见任务上提升最大。对技能生命周期的分析显示，随着策略的改进，技能被自动创建、测试、改进和修剪，展示了协调的技能-策略共同演化。

## Abstract
Agentic reinforcement learning (RL) enables LLM agents to improve continuously from environment rewards, yet the resulting policies do not systematically accumulate reusable strategies that generalize across tasks. Modular skills can provide such reusable strategies, yet existing skill-augmented RL methods decouple skill creation from policy optimization, risking adopting skills that conflict with the evolving policy. Inspired by Anthropic's Skill Creator, we introduce ReSkill, an RL-in-the-loop skill creation framework that reconciles skill evolution with policy learning. ReSkill exploits the group-wise structure of GRPO to naturally embed three mechanisms with only marginal additional overhead: (1) an assertion-driven skill creator that diagnoses failures from past experience and proposes conditional, trigger-based skill revisions; (2) within-group rollout sampling that enables controlled comparison of skill versions, capturing which version best supports the policy's ongoing learning; and (3) Thompson Sampling with adaptive discounting to balance exploration and exploitation in skill version selection as the policy evolves. Across several domains, ReSkill consistently outperforms existing memory and skill-based RL methods, with the largest gains on unseen tasks. Analysis of the skill lifecycle shows skills being automatically created, tested, refined, and pruned as the policy improves, demonstrating reconciled skill-policy co-evolution.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有的智能体强化学习（Agentic RL）虽然通过 GRPO 等算法能从环境奖励中持续改进策略，但训练得到的策略无法系统地积累可跨任务泛化的可复用策略（即技能）。而现有的技能增强型 RL 方法（如 SkillRL、MemRL 等）将**技能创建**与**策略优化**解耦为两个独立流程，导致技能可能与不断演化的策略产生冲突，甚至损害策略性能。
- **背景**：Anthropic 的 Skill Creator 展示了通过人机协作创建模块化技能的有效性，但它在静态策略下运行且依赖人类反馈。能否将技能创建整合到 RL 训练循环中，实现技能与策略的协同进化？
- **整体含义**：提出了 ReSkill 框架，首次实现在 RL 训练过程中动态创建、测试、接受/拒绝技能版本，与策略优化同步进行，从而避免技能-策略冲突，提升跨任务泛化能力。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **在 RL 训练循环内嵌入技能创建与评估**，利用 GRPO 天然的分组结构（组内 rollouts 共享相同任务和策略，只改变技能版本）实现零额外 rollout 开销的技能比较。
- **三个关键机制**：
  1. **断言驱动的技能创建器**：从训练轨迹中诊断失败模式，自动生成或更新技能。
  2. **组内 rollout 采样**：在同一个 GRPO 组内分配不同的技能版本，实现受控对比。
  3. **自适应折扣的 Thompson Sampling**：在技能版本选择中平衡探索与利用，并根据策略演化动态调整历史证据权重。

### 关键技术细节
- **GRPO 目标扩展**：标准 GRPO 每个组采样 G 条轨迹，使用组内归一化优势估计。ReSkill 将其扩展为 **J_RESKILL**(θ) = E[L_GRPO(θ; {τ_i})]，其中每个 rollout 的技能版本 v_i 从 Thompson Sampling 分布中采样，轨迹 τ_i 在对应技能库 S_{v_i} 下生成。
- **技能加载**：每个技能由条件触发（trigger）和技能内容（when_to_use、action、examples）组成，只有触发条件满足时技能才被加载到上下文，保持上下文紧凑。
- **经验蓄水池**：持续收集训练过程中的成功/失败轨迹及其技能版本标签，用于驱动技能创建。
- **断言分析**：动态维护一组规则断言（如动作顺序、长度约束等），对整个蓄水池进行评分，生成基于流行度的失败诊断，指导技能修订。
- **版本分配**：将新版本和旧版本视为两个臂，使用 Beta 后验建模成功概率。每步估计 Pr(p_new > p_old)，截断后得到分配概率 π_t(new)，然后独立分配组内每个 rollout 的技能版本。
- **自适应折扣**：后验更新时，对历史伪计数使用折扣 w_t = 1/(1 + n_t/M)，其中 n_t 是当前步分配给该版本的轨迹数，M 为记忆参数（通过顺序预测似然最大化自动估计）。这样，获得较多样本的版本会更快忘记旧证据，适应策略漂移。
- **接受/决策**：每个演化周期结束后，若后验期望 E[p_new] > E[p_old]，则接受新版本，否则回退到旧版本。

### 算法流程（文字说明）
1. 初始化策略、技能库、蓄水池和 Beta 后验。
2. 每步 t：
   - 采样任务 q，根据当前后验计算每个 rollout 的技能版本分配概率。
   - 生成 G 条轨迹，同时获得奖励。
   - 使用 **J_RESKILL** 更新策略。
   - 将轨迹加入蓄水池。
   - 更新后验伪计数（含自适应折扣）。
3. 每 Ke 步：
   - 根据后验决定是否接受当前候选新技能（若接受则作为新基线）。
   - 运行技能创建器：蓄水池断言评分 → 对比分析 → 聚类 → 推荐 → 作者编写新候选版本。
   - 重置后验，开始新一轮测试。

## 3. 实验设计

### 数据集/场景
- **Embodied reasoning**：ALFWorld（家居环境，分 Pick&Place、Transform、Examine 三类任务，有 seen/unseen 拆分）。
- **Agentic search**：训练集 NQ + HotpotQA，测试集包括 PopQA、TriviaQA、2WikiMHQA、MuSiQue、Bamboogle 等 5 个未见数据集。
- **Science discovery (ScienceWorld)**：电学任务，分 ID（分布内）和 OOD（分布外）。
- **Coding (InterCode-SQL)**：基于 Spider 数据库的交互式 SQL 生成，按 Hard/Extra-hard 难度分层。
- **Web shopping (WANDS)**：产品搜索，分 2-opt 和 3-opt 难度。

### Benchmark 对比方法
- **Baselines**：ReAct（基模型）、Claude 4.5 Sonnet（闭源强模型）。
- **Evolvement 方法（无 RL）**：ReMe、MemRL。
- **Skill-only 方法（无 RL）**：从 SkillRL 获取 oracle 技能库，使用 BM25、HippoRAG 检索或长上下文全量加载。
- **RL-based 方法**：GRPO（无技能）、MemRL（+RL）、EvolveR、INSPO、SkillRL。
- 所有方法统一使用 Qwen3-4B-Instruct 和 Qwen3-8B 作为基模型，技能/记忆创建默认使用 Claude 4.5 Sonnet（对比实验也使用基模型创建）。

## 6. 主要结论与发现

- **ReSkill 全面超越所有基线**：在 ALFWorld 上达到 89.8%（4B）/ 92.7%（8B），比 SkillRL 高 5.9%/6.9%；在 Search 上达到 47.6%/49.8%，比 SkillRL 高 2.5%/2.3%。
- **未见任务提升最大**：ALFWorld unseen 分项提升 12.7%（8B），Search unseen 提升幅度约为 seen 的 2.1 倍。
- **消融实验验证各组件必要性**：auto-accept 导致性能崩溃（ALFWorld 62.7% 低于 GRPO 75.3%），uniform allocation 不如 Thompson Sampling，自适应折扣优于固定折扣。
- **共进化顺序重要**：同时共进化优于顺序执行（skill-first 或 policy-first）。
- **断言分析器提升诊断精度**，去除后下降 5.1%（ALFWorld）。
- **测试时跨域适应**：冻结 ALFWorld 策略，在 ScienceWorld 上只更新技能，很快达到强泛化，而基线几乎为零。
- **技能生命周期**：技能自动创建、测试、精炼、修剪，与策略改善同步。

## 7. 优点

- **方法创新**：首次在 GRPO 训练循环内嵌入技能创建与测试，实现零额外 rollout 开销的技能-策略共进化。
- **理论扎实**：自适应 Thompson Sampling 和后验折扣的设计考虑了策略漂移，参数通过预测似然自动估计，无需手动调参。
- **实验全面**：涵盖 embodied、search、coding、shopping、scientific discovery 五个领域，模型尺度从 4B 到 8B，消融实验系统。
- **效率好**：条件技能加载使上下文紧凑，成本仅略高于 GRPO（约 1.1 倍时间，1.1 倍训练上下文长度）。
- **可迁移性**：策略学会“跟随技能”，在测试时仅通过技能创建即可适应新领域。

## 8. 不足与局限
