## 摘要
智能体技能是使LLM智能体能够执行工作流、验证约束并从失败中恢复的程序性产物。现有的自进化方法利用累积轨迹来完善技能，但在冷启动场景中难以奏效，此时仅存在一个初始的不完美技能。因此，技能构建通常默认采用专家编写或一次性LLM生成。专家编写的技能成本高昂，且可能与LLM智能体实际执行任务的方式不一致；而一次性生成的技能可能在语法上良好但在行为上薄弱。为弥合这一差距，我们提出SkillRevise——一个基于执行过程的框架，旨在迭代改进这些初始技能。SkillRevise从执行证据中诊断技能缺陷，从通用记忆中检索相关修复原则，并应用基于执行的编辑。通过重新执行候选技能并测量经验效用，它系统性地保留最优技能版本。在三个基准测试和五个LLM上的评估表明，SkillRevise显著优于一次性基线方法，将基础智能体在SkillsBench上的成功率从36.05%提升至61.63%。此外，改进后的技能表现出强跨模型迁移能力，在模型特定产物上捕获了通用化的程序知识。

## Abstract
Agent skills are procedural artifacts that enable LLM agents to execute workflows, verify constraints, and recover from failures. Existing self-evolving methods refine skills using accumulated trajectories. However, they struggle in cold-start settings, where only an initial, imperfect skill is available. Consequently, skill construction defaults to expert authoring or one-shot LLM generation. Expert-authored skills are costly and may not align with how LLM agents actually execute tasks, while one-shot generated skills can be syntactically well formed yet behaviorally weak. To bridge this gap, we propose SkillRevise, an execution-grounded framework designed to iteratively refine these initial skills. SkillRevise diagnoses skill defects from execution evidence, retrieves relevant repair principles from a general memory, and applies execution-anchored edits. By re-executing candidates and measuring empirical utility, it systematically retains the optimal skill version. Evaluated across three benchmarks and five LLMs, SkillRevise substantially outperforms one-shot baselines, improving the base agent's success rate on SkillsBench from 36.05% to 61.63%. Furthermore, the revised skills exhibit strong cross-model transferability, capturing generalized procedural knowledge over model-specific artifacts.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将冷启动技能改进视为**有界、基于执行的修订**（Bounded, Execution-Grounded Revision），而非检索或开放式自我进化。SkillRevise 将修订拆解为**任务特定执行证据**（诊断）与**通用可复用修复知识**（原则记忆）的耦合，通过**执行-诊断-检索-修订-重执行-效用门控选择**的循环，在有限预算内保留最佳观察技能。

- **关键技术细节**：
  - **诊断（Diagnosis）**：由验证规范、失败归因和保留约束组成，将原始执行证据转化为修复约束。
  - **原则记忆（Principle Memory）**：存储可复用修复原则，每个原则包含触发条件、缺陷类型、修复规则、动作模板、验证模板和不可转移条件。初始包含七个原则。
  - **修订算子（Revision Operator）**：给定当前技能、诊断和绑定原则，生成修订候选技能和修订轨迹（包括应用原则、目标区间、执行锚点等）。执行锚点指定文本编辑如何改变执行器行为（具体动作、证据检查、位置）。
  - **有界修订回合（Bounded Revision Episode）**：
    - 维护当前技能、最佳技能和候选集。
    - 每轮执行技能 → 诊断 → 若存在技能级缺陷则检索原则（混合检索：稀疏+稠密，加权倒数秩融合）→ 绑定原则 → 生成候选 → 重执行 → 效用门控更新最佳技能。
    - 效用门控（Utility-Gate）由成功率、效率、迁移性能和干扰成本加权计算，且仅在成功时奖励效率。
    - 默认预算 B=3 轮，返回最佳观察技能（不一定是最后生成的）。

## 6. 论文的主要结论与发现

- **主要结论**：SkillRevise 通过执行锚定的迭代修订显著提升 LLM 智能体技能质量。在 SkillsBench 上，GPT-5.5 成功率从 36.05%（无技能）和 39.53%（一次性生成）提升至 61.63%（三轮修订）。在所有三个基准和五个执行器上，Revision v3 一致优于一次性基线（除个别情况）。
- **关键发现**：
  - **增益前端加载**：首轮修订贡献最大，后续递减但仍有帮助。
  - **效用门控防止退化**：即使更多轮次，最佳技能常来自早期版本。
  - **诊断是最关键组件**：移除诊断导致成功率从 53/86 降至 28/86。
  - **原则记忆和保留账本重要**：提供可复用修复模式并防止回归。
  - **跨模型迁移性部分成立**：GPT-5.5 修订的技能能提升其他执行器，但本模型定制技能通常更强。
  - **Revision 可修复由技能引起的错误**：即使无技能已成功的任务，Revision 可添加保护措施避免副作用。
  - **仍存在残留失败**：部分任务技能条件化反而有害，无技能探索更优，且预算未提供回落机制。

## 7. 优点

- **方法创意**：将冷启动技能改进形式化为有界、基于执行、效用门控的修订，结合任务特定诊断和通用原则记忆，避免了检索/自我进化/直接编写的不足。
- **可解释性**：结构化诊断（验证规范、失败归因、保留约束）和修订轨迹提供透明的证据到编辑映射。
- **通用性**：在不同基准、不同模型（闭源/开源）上均有效，且技能展示跨模型迁移能力。
- **实验严谨性**：消融实验隔离每个组件贡献；预算实验揭示边际收益；领域级分析排除虚假增益；人工泄露审计确认无答案泄露。
- **实践价值**：提供实际部署可用的框架，初始原则记忆无需大量数据，可选在线吸收。

## 8. 不足与局限

- **验证器依赖**：修订质量完全取决于验证器反馈的密度和准确性。稀疏或错位测试可能导致过拟合可见检查。
- **成本开销**：额外的模型调用、工具使用、耗时。固定预算（maxrev3）不一定最优：易任务无需修订，难任务可能需更多轮次或领域特定方法。
- **无无技能回落**：当任务更适合直接探索时，技能条件化仍可能有害，框架未提供回退到无技能执行机制。
- **评估范围有限**：仅限于可重复测试验证的基准，未涉及长期部署、安全关键场景、对抗环境或用户定义成功标准。
- **迁移性不完全**：跨模型迁移增益不对称，部分执行器从他人技能获益有限，表明技能中包含模型特定提示习惯。
- **原则记忆初始化**：手工编写原则可能未覆盖所有缺陷类型，ALFWorld 吸收展示了扩展性但规模小。
- **重现性细节**：未提供完整超参数设置（如融合常数 κ，权重 α,β,γ,λ），可能影响精确复现。
