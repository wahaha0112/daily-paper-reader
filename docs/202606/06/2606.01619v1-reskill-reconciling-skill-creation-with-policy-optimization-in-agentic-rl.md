## 摘要
智能体强化学习使大型语言模型智能体能够从环境奖励中持续改进，然而所得策略并未系统性地积累可跨任务泛化的可复用策略。模块化技能可以提供这种可复用策略，但现有的技能增强型强化学习方法将技能创建与策略优化分离，存在采用与演化策略相冲突的技能的风险。受Anthropic's Skill Creator启发，我们提出了ReSkill，一种将技能演化与策略学习相协调的强化学习循环技能创建框架。ReSkill利用GRPO的群体结构，仅以微小额外开销自然嵌入三种机制：（1）基于断言的技能创建器，从过往经验中诊断失败并提出条件性、基于触发的技能修订；（2）组内轨迹采样，实现对技能版本的受控比较，捕捉哪个版本最能支持策略的持续学习；（3）采用自适应折扣的汤普森采样，在策略演化过程中平衡技能版本选择的探索与利用。在多个领域中，ReSkill持续优于现有基于记忆和技能的强化学习方法，在未见任务上提升最大。对技能生命周期的分析显示，随着策略改进，技能被自动创建、测试、优化和修剪，展现了协调的技能-策略共同演化。

## Abstract
Agentic reinforcement learning (RL) enables LLM agents to improve continuously from environment rewards, yet the resulting policies do not systematically accumulate reusable strategies that generalize across tasks. Modular skills can provide such reusable strategies, yet existing skill-augmented RL methods decouple skill creation from policy optimization, risking adopting skills that conflict with the evolving policy. Inspired by Anthropic's Skill Creator, we introduce ReSkill, an RL-in-the-loop skill creation framework that reconciles skill evolution with policy learning. ReSkill exploits the group-wise structure of GRPO to naturally embed three mechanisms with only marginal additional overhead: (1) an assertion-driven skill creator that diagnoses failures from past experience and proposes conditional, trigger-based skill revisions; (2) within-group rollout sampling that enables controlled comparison of skill versions, capturing which version best supports the policy's ongoing learning; and (3) Thompson Sampling with adaptive discounting to balance exploration and exploitation in skill version selection as the policy evolves. Across several domains, ReSkill consistently outperforms existing memory and skill-based RL methods, with the largest gains on unseen tasks. Analysis of the skill lifecycle shows skills being automatically created, tested, refined, and pruned as the policy improves, demonstrating reconciled skill-policy co-evolution.

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：现有智能体强化学习（Agentic RL）使LLM智能体能够从环境奖励中持续改进策略，但所得策略并不系统性地积累可跨任务复用的模块化技能。现有的技能增强型RL方法将技能创建与策略优化分离（如Anthropic's Skill Creator依赖静态策略和人工反馈，或MEMRL、SkillRL等独立优化技能），这可能导致技能与演化中的策略产生冲突，无法实现策略与技能的协同进化。
- **整体含义**：本文提出**ReSkill**，将技能创建过程嵌入RL训练循环，使技能与策略在同一个优化过程中共同进化，从而避免冲突、提升样本效率，并使得策略能够系统地利用可复用的技能知识。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：利用GRPO（Group Relative Policy Optimization）的组结构（每组G条轨迹共享同一任务和同一策略），在每组内分配不同的技能版本，实现低成本、可控的技能对比测试。每个rollout同时服务三个角色：策略梯度更新、失败诊断经验收集、版本评估（Thompson Sampling）。
- **三个内嵌机制**：
  1. **断言驱动的技能创建器（Assertion-Driven Skill Creator）**：从持续更新的经验池中提取成功-失败轨迹对，通过一组动态断言规则评估失败模式，再由LLM提出ADD/MODIFY/DELETE操作生成新技能版本S_new。
  2. **组内rollout采样（Within-Group Rollout Sampling）**：每个训练步，对组内每个rollout独立从Thompson Sampling后验中分配技能版本（S_new或S_old），从而在同一组内直接比较不同版本的效果，无需额外测试rollout。
  3. **自适应折扣Thompson Sampling**：采用Beta-Bernoulli模型跟踪每个技能版本的成功概率；后验更新时引入自适应折扣权重 w_t = 1/(1 + n_t/hat{M})，根据当前步分配给该版本的样本数动态调整旧证据的保留程度，平衡非平稳策略下的探索与利用。每个评估周期结束时，若E[p_new] > E[p_old]则接受新版本。

## 6. 主要结论与发现
- **一致提升**：ReSkill在所有领域和两个模型尺度上均优于所有基线。非RL方法落后22.0-32.3%（ALFWorld），RL方法中ReSkill比最强技能增强RL基线高5.9%/6.9%（ALFWorld 4B/8B）和2.5%/2.3%（Search）。
- **未知任务增益更大**：在ALFWorld unseen上8B模型ReSkill达95.3%，比SKILLRL高12.7%；Search上未见任务提升幅度约为已见任务的2.1倍。表明协同进化保留了泛化性更好的技能版本。
- **技能生命周期**：训练中技能自动经历创建、测试、精炼、修剪，与策略共同演化。早期构建基础技能，后期转向精炼和删除已内化的技能。
- **消融验证**：自动接受所有提议技能（auto-accept）导致性能崩溃（ALFWorld上降至62.7%，低于GRPO的75.3%），证明测试的必要性；均匀分配版本（uniform）表现次优；自适应折扣优于最后一步或均匀加权；顺序协同（先技能后策略或反之）远不如同时协同；断言分析器带来额外提升。
- **跨域适应**：冻结策略后，仅通过技能创建即可在新域（ScienceWorld）上迅速适应，表明协同训练训练出了遵循和受益于新技能的一般能力。

## 7. 优点：方法或实验设计上的亮点
- **零额外rollout成本**：组内采样使得技能评估不增加任何额外rollout，每个rollout同时服务三个目的。
- **自然嵌入GRPO**：利用GRPO的组结构天然提供受控对比环境，无需修改RL算法核心。
- **自适应Thompson Sampling**：通过自适应折扣处理非平稳策略环境，并自动估计记忆参数hat{M}，无需手动调参。
- **断言驱动诊断**：规则化断言集驱动技能修订，结合LLM分析，避免对每轨迹单独调用LLM，提升效率。
- **条件触发器**：只有触发条件满足时技能才加载到上下文，保持推理上下文紧凑，降低开销（图6）。
- **广泛实验覆盖**：五个不同领域、两个模型尺度、系统消融、敏感性分析、跨域适应、定性案例，论证充分。

## 8. 不足与局限
- **进化频率需调参**：性能对K_e敏感（尤其在短训练步数的场景），论文未提供自适应进化调度方案，依赖手动设置。
- **技能调用可能被误用**：小模型有时将技能名称当作环境动作输出（“meta-bug”），或过度应用技能于不适用的情境，说明基础模型容量限制可能妨碍正确理解技能的角色。
- **技能容量负担**：技能注入增加上下文长度，对较小模型造成认知负荷，可能导致混淆。
- **基模型能力依赖**：虽然用基模型创建技能的消融仍优于所有基线，但使用更强LLM（Claude）进行技能创建仍带来额外提升，说明技能质量仍受创建模型影响。
