## 摘要
智能体系统越来越多地使用文本技能来编码可重用的任务流程，但每一步将这些技能注入提示会产生大量的上下文开销，并将技能内容暴露为明文。我们提出了LatentSkill，一个通过预训练超网络将文本技能转换为即插即用LoRA适配器的框架。LatentSkill将技能知识存储在权重空间而非上下文空间，在保持模块化加载、缩放和组合的同时去除了每步技能令牌。在ALFWorld和Search-QA上，LatentSkill在显著减少预填充令牌的同时，性能优于相应的上下文技能基线：在可见和不可见分集上，ALFWorld成功率分别提高了21.4和13.4个百分点，预填充令牌减少了64.1%；Search-QA精确匹配提高了3.0个百分点，技能令牌开销降低了72.2%。进一步分析表明，生成的技能LoRA形成了结构化的语义几何形状，可以通过LoRA缩放系数精确控制，并且当技能组件对齐时，可以通过参数空间算术进行组合。这些发现表明，权重空间技能为扩展LLM智能体提供了一种高效、模块化且暴露较少的基板。

## Abstract
Agent systems increasingly use textual skills to encode reusable task procedures, but injecting these skills into the prompt at every step incurs substantial context overhead and exposes skill content as plaintext. We present LatentSkill, a framework that converts textual skills into plug-and-play LoRA adapters through a pretrained hypernetwork. LatentSkill stores skill knowledge in weight space rather than context space, removing per-step skill tokens while preserving modular loading, scaling, and composition. On ALFWorld and Search-QA, LatentSkill outperforms the corresponding in-context skill baseline while using substantially fewer prefill tokens: it improves ALFWorld success by 21.4 and 13.4 points on the seen and unseen splits with 64.1% fewer prefill tokens, and improves Search-QA exact match by 3.0 points with 72.2% lower skill-token overhead. Further analysis shows that generated skill LoRAs form a structured semantic geometry, can be precisely controlled via the LoRA scaling coefficient, and can be composed through parameter-space arithmetic when skill components are aligned. These findings suggest that weight-space skills provide an efficient, modular, and less exposed substrate for extending LLM agents.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题**：LLM智能体系统在使用外部文本技能（textual skills）时，通常将技能作为自然语言文本注入到提示词（prompt）中。这导致两个严重问题：
  - **上下文开销**：技能文本在每步决策中重复注入，消耗上下文窗口，增加预填充（prefill）成本和推理时间。
  - **暴露风险**：技能内容以明文形式存在于提示中，可能被恶意攻击（如提示注入）窃取或干扰，且共享指令通道可能受到污染。
- **现有方法的不足**：
  - 传统上下文技能方法（In-context Skill）虽然模块化，但无法避免上述问题。
  - 参数化方法（如微调、课程学习）将技能融合进模型参数，丧失模块化、可更新和可组合性。
- **整体目标**：在避免重复技能文本的同时，保持技能的模块化、可更新和推理时可组合性。论文提出 **LatentSkill**，将文本技能转换为LoRA适配器存储在权重空间中，实现高效、低暴露、可插拔的技能表示。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：通过一个预训练的**超网络（Hypernetwork）**，将文本技能文档映射为一组LoRA参数更新（即隐式技能），再挂载到冻结的骨干LLM上。推理时，提示中不再包含技能文本，仅通过LoRA适配器注入技能知识。
- **关键技术细节**：
  - **Latent Skill定义**：给定文本技能文档s，超网络Gϕ生成LoRA更新Δs = Gϕ(s)。挂载后，模型仅根据历史ht预测输出：pθ⊕αΔs(yt | ht)，其中α为注入系数。
  - **两阶段训练**：
    1. **文档预训练（Skill Document Pretraining）**：在约171K GitHub爬取的去重技能文档（约300M tokens）上训练超网络。两个任务：重建（根据完整技能文档预测原文档）和补全（根据前缀预测后续内容）。目标是通过生成适配器使模型完成文档级预测，迫使超网络学会编码技能知识。
    2. **轨迹有监督微调（Trajectory-Supervised Fine-Tuning）**：使用教师代理轨迹（237条ALFWorld和500条Search-QA轨迹）进行端到端训练。超网络从技能文档生成适配器，并在整个轨迹中保持不变，目标函数是最大化教师动作的似然。骨干模型始终冻结。
  - **推理时操作**：
    - 单技能：从缓存加载LoRA适配器，挂载并设置α。
    - 多技能组合：在参数空间线性叠加适配器：ΔK = Σ αk C[k]。
    - 组件级组合：将技能分解为语义组件，分别编译后选择性叠加，避免共享组件重复放大。
- **公式与流程**（文字说明）：
  - 预训练阶段：对于每个技能文档，超网络生成Δpre，骨干模型输入查询qi，预测目标输出zi，损失为交叉熵，只更新超网络。
  - SFT阶段：给定技能si和轨迹τi，超网络生成Δsft，在同一轨迹的所有步骤中使用同一适配器，损失累加所有步骤的交叉熵，只更新超网络。

## 3. 实验设计：使用数据集/场景、Benchmark、对比方法

- **Benchmark**：
  - **ALFWorld**：文本交互式家庭任务，6类子任务（Pick, Look, Clean, Heat, Cool, Pick2）。分为可见（seen）和不可见（unseen）分片，共274个episode（seen 140, unseen 134）。
