## 摘要
大语言模型智能体越来越多地依赖可重用的外部技能来解决长程交互任务。现有的无训练技能适应流程通常从完整轨迹或会话级反馈更新技能，这导致故障归因粗粒度，往往产生不稳定或过度宽泛的修订。我们提出SkillAdaptor，一种无训练的步骤级技能适应框架，具有显式的故障归因，可插入OpenClaw类智能体框架。给定一个失败轨迹，SkillAdaptor识别第一个可操作故障步骤，将责任链接到候选技能，并在显式接受检查下应用针对性更新，同时保持骨干模型冻结。我们在WebShop、PinchBench和Claw-Eval上使用Kimi-K2.5、GLM-5和GPT-5.2进行评估。SkillAdaptor在所有三个数据集上均优于无技能和技能适应基线，最大单指标提升分别为PinchBench平均分+1.5个百分点、Claw-Eval平均分+1.8和WebShop成功率+1.7个百分点。这些结果表明，步骤级归因能够支持更稳定且可审计的无训练技能维护\footnote{代码将发布于https://github.com/zjunlp/SkillAdaptor。}

## Abstract
Large language model (LLM) agents increasingly rely on reusable external skills to solve long-horizon interactive tasks. Existing training-free skill adaptation pipelines usually update skills from full trajectories or session-level feedback, which makes failure attribution coarse and often produces unstable or overly broad revisions. We propose SkillAdaptor, a training-free step-level skill adaptation framework with explicit failure attribution, and it can plug into OpenClaw-class agent harnesses. Given a failed trajectory, SkillAdaptor identifies a first actionable fault step, links responsibility to candidate skills, and applies targeted updates under explicit acceptance checks while keeping the backbone frozen. We evaluate on WebShop, PinchBench, and Claw-Eval with Kimi-K2.5, GLM-5, and GPT-5.2. SkillAdaptor improves over no-skill and skill-adaptation baselines on all three suites, with the largest single-metric improvements of +1.5 points on PinchBench Avg Score%, +1.8 on Claw-Eval Avg Score, and +1.7 on WebShop success rate. These results indicate that step-level attribution supports more stable and auditable training-free skill maintenance\footnote{The code will be released at https://github.com/zjunlp/SkillAdaptor.}.

## 2. 方法论
### 核心思想
- 将技能适应从轨迹级反思细化为步骤级归因：给定一条失败轨迹，定位第一个可操作的故障步骤，诊断具体技能缺陷，然后仅定向更新相关技能，保持其他技能不变。
- 框架可插入OpenClaw类智能体框架，无需训练骨干模型。

### 关键技术细节（三阶段流程）
1. **归属阶段（Attribution）**：
   - **Localizer**：根据任务描述、轨迹、已检索技能，预测首个可归因故障步骤 \( t^* \) 及失败行为描述与改进建议。
   - **Linker**：将责任权重分配给候选技能，输出加权嫌疑技能集 \(\{(s_j, w_j)\}\)，并预测适应动作 \(\hat{a} \in \{ \text{REVISE}, \text{GENERATE} \}\)。若失败源于已有技能误导则修订，若源于技能缺失则生成新技能。

2. **修改阶段（Modification）**：
   - **Modifier**：根据动作类型执行操作：
     - 若 \(\hat{a} = \text{REVISE}\)：重写最高权重技能并替换原技能。
     - 若 \(\hat{a} = \text{GENERATE}\)：从故障步骤上下文合成新技能并加入集合。
   - 使用语义相似度阈值 \(\theta_{dup} = 0.95\) 抑制冗余增长。

3. **资格阶段（Qualification）**：
   - 对每个候选更新，重新执行任务集比较更新前后的性能差异 \(\Delta\)。仅当 \(\Delta \ge 0\) 时接受更新，否则丢弃。
   - 最多迭代10轮，或连续3轮无变化则停止。

### 技能初始化与注入
- 初始无外部技能，先执行任务集，从成功轨迹中提取初始技能构建 \(K_0\)。
- 后续执行时，任务嵌入与技能嵌入（使用Qwen3-Embedding-8B）进行余弦相似度检索，取top-10候选，由骨干LLM重排序后注入。

## 6. 主要结论与发现
- **核心结论**：SkillAdaptor在所有三个基准上均一致优于无技能基线和现有技能适应基线。最大单指标提升包括：
  - WebShop成功率+1.7个百分点（Kimi-K2.5），分数+2.3（GLM-5）
  - PinchBench平均分+1.5个百分点（GLM-5）
  - Claw-Eval平均分+1.8（Kimi-K2.5）
- **步骤级归因优于轨迹级**：去除Localizer和Linker后WebShop成功率从33.0%降至28.6%，Claw-Eval平均分从75.8降至74.5，表明步骤级定位是有效修订的关键。
- **资格门控提升稳定性**：去除Qualifier后标准差增大（如PinchBench ±8.1 vs ±5.2），且WebShop成功率下降至26.3%，说明过滤有害更新至关重要。
- **早期适应为主**：大多数接受更新发生在第1-2轮（WebShop约75%，Claw-Eval和PinchBench约64-65%），此后收益递减。
- **适用场景**：技能适应最有效于故障信号可定位、执行轨迹暴露中间结构的任务（如数据、代码任务）；在依赖外部状态或跨会话上下文的场景（研究、记忆、安全任务）中改进较小。

## 7. 优点
- **轻量无训练**：无需更新骨干模型参数，仅对技能文本进行修改，计算开销低。
- **模块化可插拔**：可插入OpenClaw类智能体框架，与其他系统兼容。
- **精确故障归因**：步骤级定位避免了轨迹级汇总造成的信号扩散，使修订更精准。
- **安全性保障**：资格阶段（Qualifier）通过实际执行验证更新效果，防止有害修订积累；冗余检测（\(\theta_{dup}=0.95\)）控制技能库膨胀。
- **实验严谨**：多模型、多基准、多次重复，消融实验系统，案例分析直观。
