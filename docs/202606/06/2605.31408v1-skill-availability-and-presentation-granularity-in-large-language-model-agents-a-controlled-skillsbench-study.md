## 摘要
技能文档在推理时为大型语言模型智能体提供程序性知识。本文研究受控技能知识的呈现粒度是否改变下游任务的成功率。实验使用固定版本的SkillsBench，一个由30个任务组成的领域平衡子集（经官方oracle运行验证），两种启用推理能力的模型配置，六种技能条件，以及每个任务-条件-模型单元五次试验。技能可用性是最清晰的经验信号。相对于无技能条件，技能条件使GPT-5.5的任务平均通过率提高26.7至36.0个百分点，使DeepSeek V4-Flash提高18.0至26.0个百分点。最终数据包含1800行，每个模型900行。任务为推理单元。在30个任务上进行配对对比估计之前，每个任务-条件-模型单元内聚合五次试验。主要的呈现对比效果较小且不确定。低抽象指导与高抽象指导相比，GPT-5.5的差异为+0.7个百分点，DeepSeek V4-Flash为-6.7个百分点，两者的95%自助法置信区间均包含零。在中抽象指导中添加一个工作示例与无示例变体相比，差异为+0.7和+1.3个百分点。平均奖励稳健性检验保留了相同的实质性结论。在这个受控子集中，技能可用性与比无技能更高的成功率相关，而所测试的呈现粒度变化产生了微小、不确定且依赖模型的效果。

## Abstract
Skill documents provide procedural knowledge to large-language-model agents at inference time. This article studies whether the presentation granularity of controlled skill knowledge changes downstream task success. The experiment uses a pinned SkillsBench version, a 30-task domain-balanced subset validated by official oracle runs, two reasoning-enabled model configurations, six skill conditions, and five trials per task-condition-model cell. Skill availability is the clearest empirical signal. Relative to no skill, skill conditions increase task-mean pass rate by 26.7 to 36.0 percentage points for GPT-5.5 and by 18.0 to 26.0 percentage points for DeepSeek V4-Flash. The final data contain 1,800 rows, with 900 rows for each model. The task is the inference unit. Five trials are aggregated within each task-condition-model cell before paired contrasts are estimated over 30 tasks. The primary presentation contrasts are smaller and uncertain. Low-abstraction guidance differs from high-abstraction guidance by +0.7 percentage points for GPT-5.5 and -6.7 percentage points for DeepSeek V4-Flash, with both 95% bootstrap confidence intervals crossing zero. Adding one worked example to medium-abstraction guidance differs from the no-example variant by +0.7 and +1.3 percentage points. Mean-reward robustness checks preserve the same substantive conclusion. In this controlled subset, skill availability is associated with higher success than no skill, while the tested presentation-granularity changes yield small, uncertain, and model-dependent effects.

# 2. 方法论

## 核心思想
- 将技能文档视为一种上下文干预变量，在固定任务、固定模型配置、固定其他条件的前提下，仅改变技能文档的呈现形式（抽象层级、示例有无），并测量其对任务通过率的影响。
- 采用严格的内容控制流程：从源技能文档生成四种改写变体，通过结构性审计、风格审计、覆盖审计减少内容漂移。

## 关键技术细节
- **六种技能条件**：
  - `no_skill`：无技能文档。
  - `original_curated`：官方SkillsBench技能文件逐字节拷贝。
  - `high_abstract`：重写为原则、不变性、决策规则，无示例。
  - `medium_no_example`：中等抽象，提供过程性指导和易错点，无示例。
  - `medium_with_example`：中等抽象，添加一个简短工作示例。
  - `low_abstract`：低抽象，检查清单式、具体占位符、逐步恢复检查，无示例。
- **统计推断**：
  - 单元为任务（task-level），每个任务-条件-模型单元内聚合5次试验为通过率。
  - 主要对比：配对任务级差异均值，95% bootstrap置信区间（10,000次重采样），配对蒙特卡洛符号翻转置换p值（100,000次样本），并应用Holm校正。

# 6. 主要结论与发现

1. **技能可用性是最大信号**：
   - GPT-5.5：技能条件比无技能通过率提高26.7–36.0个百分点（所有bootstrap CI均>0）。
   - DeepSeek V4-Flash：提高18.0–26.0个百分点（所有bootstrap CI均>0）。
2. **呈现粒度效果微小且不确定**：
   - RQ1（低抽象–高抽象）：GPT-5.5 +0.7 pp（CI [-10.0, +12.0]）；DeepSeek -6.7 pp（CI [-14.7, +0.7]），Holm校正p值>0.05。
   - RQ2（中抽象+示例 – 中抽象无示例）：GPT-5.5 +0.7 pp；DeepSeek +1.3 pp，CI均跨零。
3. **原始技能的重写版本倾向于略低于原始curated技能**（GPT-5.5下降5.3–9.3 pp；DeepSeek高抽象略高+1.3 pp，其他下降5.3–6.7 pp），但所有CI均跨零。
4. **平均奖励稳健性检验**未改变实质性结论，仅细微符号变化。
5. 结论：**技能可用性是关键因素，而测试的呈现粒度变化（抽象层次、添加一个示例）对任务成功率影响微弱且不确定**；建议关注提供相关技能本身，而非精细调整其呈现形式。

# 7. 优点

- **严谨的控制设计**：固定基准版本、冻结哈希保护文件完整性、分离最终行与尝试行、记录执行修正，增强了内部效度。
- **清晰分离变量**：同时操纵技能可用性和呈现粒度，但将可用性作为背景，粒度作为主对比，避免混淆。
- **统计方法扎实**：使用任务级配对分析（而非运行级虚假独立），bootstrap CI、置换检验、Holm校正，并报告敏感性分析。
- **透明度高**：公开预注册协议、内容控制流程、执行修正列表、完整数据包（待发布），便于复现。
- **多模型验证**：在两种不同模型（GPT-5.5和DeepSeek V4-Flash）上重复实验，观察效果一致性和差异。

# 8. 不足与局限

- **实验覆盖有限**：
  - 仅30个任务的子集（非完整SkillsBench），且难度标签为描述性，可能无法推广到全部基准。
  - 仅测试两种模型，且模型配置不对称（不同推理努力设置），跨模型比较仅能描述不能推断。
- **内容控制近似性**：
  - 重写变体虽经审计，但无法保证语义等价，可能引入长度、顺序、术语、格式等残余混淆（特别是抽象对比中）。
  - 原始curated技能包含的语法细节（如命名惯例、文件内线索）可能在重写中丢失，影响效果。
- **统计效力不足**：
  - 30个任务配对只能检测约8–16个百分点的效果，对于1–2个百分点的小效果分辨率不足，可能导致假阴性。
  - 所有主要对比的CI跨零，但95% CI宽，无法完全排除中等效应存在。
- **应用限制**：
  - 仅针对SkillsBench特定设置（确定性验证器、Docker环境），不能直接推广到开放域agent或连续技能学习。
  - 失败标注和最终化规则包含部分主观授权（如操作员授权的模型超时），可能引入微观偏差。
- **呈现粒度操作中的长度共变**：低抽象指导往往更长，无法区分抽象层本身与文档长度的独立影响。
- **未分析内部规划痕迹**：关于DeepSeek在低抽象下效果更差的假设（重复或约束规划）缺乏直接证据。
