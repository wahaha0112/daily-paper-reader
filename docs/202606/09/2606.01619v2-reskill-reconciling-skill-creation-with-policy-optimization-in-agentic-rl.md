## 摘要
智能体强化学习使大语言模型智能体能够从环境奖励中持续改进，但由此产生的策略并未系统地积累可跨任务泛化的可复用策略。模块化技能可以提供此类可复用策略，然而现有的技能增强强化学习方法将技能创建与策略优化解耦，存在采纳与进化策略相冲突的技能的风险。受Anthropic的Skill Creator启发，我们提出ReSkill，一种强化学习循环内的技能创建框架，以调和技能进化与策略学习。ReSkill利用GRPO的群组结构，以仅增加少量额外开销的方式自然嵌入三种机制：（1）基于断言的技能创建器，从过往经验诊断失败并提出条件性的、基于触发的技能修订；（2）组内 rollout 采样，实现对技能版本的可控比较，捕捉哪个版本最能支持策略的持续学习；（3）采用自适应折扣的汤普森采样，在策略进化过程中平衡技能版本选择的探索与利用。在多个领域，ReSkill持续优于现有基于记忆和技能的强化学习方法，在未见任务上提升最为显著。对技能生命周期的分析显示，随着策略改进，技能被自动创建、测试、精炼和修剪，证明了技能与策略的调和共进化。

## Abstract
Agentic reinforcement learning (RL) enables LLM agents to improve continuously from environment rewards, yet the resulting policies do not systematically accumulate reusable strategies that generalize across tasks. Modular skills can provide such reusable strategies, yet existing skill-augmented RL methods decouple skill creation from policy optimization, risking adopting skills that conflict with the evolving policy. Inspired by Anthropic's Skill Creator, we introduce ReSkill, an RL-in-the-loop skill creation framework that reconciles skill evolution with policy learning. ReSkill exploits the group-wise structure of GRPO to naturally embed three mechanisms with only marginal additional overhead: (1) an assertion-driven skill creator that diagnoses failures from past experience and proposes conditional, trigger-based skill revisions; (2) within-group rollout sampling that enables controlled comparison of skill versions, capturing which version best supports the policy's ongoing learning; and (3) Thompson Sampling with adaptive discounting to balance exploration and exploitation in skill version selection as the policy evolves. Across several domains, ReSkill consistently outperforms existing memory and skill-based RL methods, with the largest gains on unseen tasks. Analysis of the skill lifecycle shows skills being automatically created, tested, refined, and pruned as the policy improves, demonstrating reconciled skill-policy co-evolution.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **ReSkill** 框架利用 GRPO（Group Relative Policy Optimization）的分组结构，在策略训练循环中嵌入三种机制：
  1. **断言驱动的技能创建器**：诊断失败经验并提出条件性、基于触发的技能修订。
  2. **组内 rollout 采样**：允许在同一组内分配不同技能版本，进行可控比较。
  3. **自适应折扣的汤普森采样**：平衡技能版本选择的探索与利用，并考虑策略演化导致的过时证据。

### 关键技术细节
- **GRPO 的分组结构**：每个训练步骤对同一任务采样 G 个 rollout，所有 rollout 共享同一任务和策略，仅技能版本不同，从而提供天然控制条件。
- **技能版本分配**：使用汤普森采样，将新旧技能版本视为两个臂，后验分布为 Beta 分布，通过蒙特卡洛采样估计新臂优于旧臂的概率，并将该概率裁剪后作为分配概率。
- **自适应折扣更新**：考虑到策略演化，使用折扣因子 wt = 1/(1 + nt/M) 来衰减历史伪计数（M 为记忆参数，通过预测似然最大化估计），使近期样本权重更大。
- **技能创建管道**：
  - 经验库：收集成功-失败轨迹对，并标注技能版本。
  - 基于断言的失败评分：动态断言集对轨迹进行规则检查，生成通过率，LLM 分析器据此提供失败诊断。
  - 历史信息驱动的技能修订：提出增加、修改、删除操作，并验证触发器触发率。
- **接受/拒绝决策**：若新技能版本的后验期望成功率大于旧版本，则接受为新基准。

### 算法流程（文字说明）
1. 初始化策略 πθ₀、技能库 S、经验库 R、Beta 后验 (α,β) 等。
2. 每步 t：
   - 采样任务 q；对每个 rollout i 根据汤普森后验分配版本 vi。
   - 生成轨迹 {τi} 并计算奖励。
   - 通过 RESKILL 目标更新策略（即 GRPO 损失，但技能版本可变）。
   - 将轨迹存入经验库，更新版本后验。
   - 每 Ke 步触发一次技能演化：根据后验接受/拒绝新版本，重置后验，更新记忆参数 M，然后由技能创建器根据经验库诊断并提出新候选。

## 7. 优点

- **创新性**：将技能创建真正嵌入到 RL 训练循环中，解决了现有方法解耦导致的冲突问题。
- **效率**：利用 GRPO 的分组结构，每个 rollout 同时服务于策略优化、失败诊断和技能评估，无需额外采样预算。
- **自适应机制**：汤普森采样加上自适应折扣权重，能适应策略演化，避免过时证据干扰。
- **广泛验证**：在多种领域（物理世界、问答、SQL、购物、科学模拟）和多个难度级别上验证，展示强泛化能力。
- **消融全面**：系统性地拆解了每个设计选择的效果，清晰地证明了各组件贡献。

## 8. 不足与局限

- **演化频率敏感性**：在 ALFWorld 上，低频演化（Ke=20）导致性能下降，且 Ke 需针对不同领域调节，存在手动调参需求。
- **技能调用控制有限**：基于触发器的技能加载会无条件注入提示，模型有时会将技能名称误当环境动作执行，或过度应用不适用技能，缺乏精细的调用控制。
- **技能容量负担**：添加技能增加上下文长度，可能对小型模型造成认知负荷，出现混淆技能指导与环境动作的问题（见案例研究）。
- **实验局限**：仅测试了 4B 和 8B 模型，未评估更大模型（如 70B+）下的表现；训练步数较少（120-250步），长期持续学习效果未知。
- **计算资源**：虽然未额外增加 rollout 预算，但技能创建依赖外部 LLM（如 Claude 4.5 Sonnet）带来 API 调用开销。
