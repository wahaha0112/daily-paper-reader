## 摘要
使机器人能够理解自然语言指令并执行任务，同时保持数据效率仍然具有挑战性。视觉-语言-动作（VLA）和视觉-语言模型（VLM）等基础模型提供了直观的交互通道，但需要大量数据；任务参数化模仿学习实现了数据效率，但缺乏自然语言基础。本工作通过一种模块化架构弥合了这一差距，该架构将任务参数化核化运动基元（TP-KMP）与预训练的VLM相结合。在学习阶段，技能通过2到5次动觉演示获得，VLM生成描述每个技能参数和前置条件的技能模式。在执行阶段，VLM解释命令以选择技能、推理参数绑定，并通过协方差加权组合创建新颖行为。当没有技能或组合满足需求时，系统会识别能力缺口并请求有针对性的演示，所有这些都无需微调。在7自由度机械臂上的验证显示，在需要技能选择、组合和主动学习的场景中，成功率达到73.3%-100%。

## Abstract
Enabling robots to understand and execute tasks from natural language commands while maintaining data efficiency remains challenging. Foundation models such as vision-language-action (VLA) and vision-language models (VLMs) provide intuitive interaction channels but require extensive data; task-parameterized imitation learning achieves data efficiency but lacks natural language grounding. This work bridges this gap through a modular architecture combining task-parameterized kernelized movement primitives (TP-KMPs) with pretrained VLMs. During learning, skills are acquired from 2 to 5 kinesthetic demonstrations, and the VLM generates skill schemas describing each skill's parameters and preconditions. During execution, the VLM interprets commands to select skills, reason about parameter bindings, and create novel behaviors through covariance-weighted composition. When no skill or composition suffices, the system identifies capability gaps and requests targeted demonstrations, all without fine-tuning. Validation on a 7-DoF manipulator shows success rates of 73.3%-100% in scenarios requiring skill selection, composition, and active learning.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **模块化架构**：将感知（物体6D位姿估计）、VLM推理（技能选择、参数绑定、模式生成）和轨迹生成（TP-KMP）解耦。VLM作为“大脑”处理语言指令，TP-KMP作为“肌肉”生成精确轨迹。
- **两个阶段**：学习阶段（通过2–5次动觉演示训练TP-KMP，VLM自动生成描述参数和前置条件的JSON技能模式）和执行阶段（VLM根据用户命令匹配技能、组合技能或触发主动学习）。
- **技能组合机制**：通过协方差加权融合（product of Gaussians）将不同技能的局部轨迹分布合成新运动，并利用形式化兼容性约束（公式1）确保融合产生连贯运动，拒绝不兼容组合。

### 关键技术细节
1. **TP-KMP训练**：将演示轨迹投影到任务相关物体（参考帧）的局部坐标系，每帧学习一个局部KMP，编码参考轨迹分布（高斯均值与协方差）。执行时根据当前物体位姿将局部预测变换到全局坐标系，通过逆协方差加权融合（公式4）得到全局轨迹。协方差自然体现演示不确定性：高一致性区域协方差小，贡献大。
2. **技能模式生成**：VLM（Qwen3-VL-32B-Instruct）接收工作台图像和检测到的物体，生成JSON格式工具定义（Listing 1），包含技能名称、所需物体类型、前置条件、后置条件、参数顺序等。此模式使VLM无需微调即可推理技能语义。
3. **技能组合与兼容性约束**（公式1）：
   - 组合时VLM从两个源技能中各选择一个局部KMP，检查其置信区间是否在时间上不重叠（即每个局部KMP只在某时间段内具有显著低的方差）。若满足（余量τ=0.01），则通过product of Gaussians融合成新TP-KMP；否则拒绝组合并触发主动学习。
4. **主动技能获取**（算法1、2）：
   - 当无技能匹配且组合不可行时，VLM检测能力缺口，生成自然语言请求（如“我没有插入技能，请演示”），用户确认后机器人进入重力补偿模式，用户通过动觉教学演示新技能（2–5次），系统训练TP-KMP并生成模式，加入技能库。

## 6. 主要结论与发现

1. **数据高效的自然语言技能学习**：CLASP只需2–5次演示即可学习技能，并通过VLM生成的模式实现语言驱动选择，无需微调VLM或大量数据。

3. **主动学习可行**：系统能可靠检测能力缺口（95%），并整合新技能（73.3%插入成功率）。

## 7. 优点

- **模块化设计**：VLM与TP-KMP解耦，可灵活替换VLM组件而不影响后端，便于工业部署和数据隐私保护。
- **形式化兼容性约束**：防止无意义的运动混合，保证组合的可预测性（避免文献中提到的平均化问题）。
- **主动学习闭环**：自动检测能力缺口并请求演示，实现持续技能库扩展，无需手动分析。
- **极低数据需求**：仅2–5次演示即可学习复杂技能，远低于VLA的需求。
- **可解释性**：TP-KMP的协方差结构提供了不确定性量化，组合过程可可视化（图10）。
- **实际硬件验证**：在7-DoF真实机器人上完成多种任务，包括高精度轴承环插入（亚毫米公差）。

## 8. 不足与局限

### 实验覆盖
- **组合限制**：仅验证两两组合，未实验三技能或以上链式组合；兼容性约束随深度增加更难满足。
- **消融缺失**：未系统分析各组件（如VLM模式生成、兼容性检查、协方差融合）的独立贡献。
- **任务多样性**：主要涉及抓取、放置、倒入、插入等基础操作，未涉及更复杂任务（如多步装配、物体操作顺序变化）。
- **静态场景假设**：物体位姿在执行期间假设不变，不适用于动态环境。
- **感知依赖**：单目相机易遮挡，导致19.7%的位姿泛化失败；需要为每个新物体类别训练6D位姿估计器（一次性成本）。

### 偏差风险
- **演示来源**：所有动觉演示由机器人专家执行，非专业用户的表现未知，可能影响泛化能力。
- **物体集**：仅使用YCB中5个物体（和轴承环），尺寸、形状多样性有限；失败的轴承环抓取表明对大物体训练的技能无法泛化到小物体。
- **硬件特定**：仅在一款机器人（DLR SARA）上验证，未测试其他平台。
- **VLM选择**：仅测试了Qwen3-VL，未报告其他VLM的鲁棒性差异。

### 应用限制
- **工业部署**：需要一次性的物体感知训练（合成数据生成+训练），虽然可摊销，但初始设置成本高于VLA的零样本泛化。
- **技能类型**：仅支持末端执行器轨迹，不支持全身运动或多臂协调。
- **组合失败的极端情况**：180°旋转附近的失败表明学习到的轨迹方向性受限，无法应对完全相反的运动方向（即使重新演示也会产生矛盾数据）。
