## 摘要
大型语言模型（LLM）智能体越来越依赖可重用的外部技能来解决长时程交互任务。现有的无训练技能自适应流程通常从完整轨迹或会话级反馈更新技能，这导致故障归因粗糙，且常产生不稳定或过于宽泛的修订。我们提出SkillAdaptor，一种具有显式故障归因的无训练步级技能自适应框架，可插入OpenClaw类智能体框架中。给定一条失败轨迹，SkillAdaptor识别第一个可操作的故障步骤，将责任关联到候选技能，并在显式接受检查下应用针对性的更新，同时保持基座模型冻结。我们在WebShop、PinchBench和Claw-Eval上使用Kimi-K2.5、GLM-5和GPT-5.2进行评估。SkillAdaptor在所有三个套件上均优于无技能和技能自适应基线，其中最大的单项指标提升分别为PinchBench平均得分%提高1.5分，Claw-Eval平均得分提高1.8分，WebShop成功率提高1.7分。这些结果表明，步级归因支持更稳定且可审计的无训练技能维护\footnote{代码将在https://github.com/zjunlp/SkillAdaptor发布。}。

## Abstract
Large language model (LLM) agents increasingly rely on reusable external skills to solve long-horizon interactive tasks. Existing training-free skill adaptation pipelines usually update skills from full trajectories or session-level feedback, which makes failure attribution coarse and often produces unstable or overly broad revisions. We propose SkillAdaptor, a training-free step-level skill adaptation framework with explicit failure attribution, and it can plug into OpenClaw-class agent harnesses. Given a failed trajectory, SkillAdaptor identifies a first actionable fault step, links responsibility to candidate skills, and applies targeted updates under explicit acceptance checks while keeping the backbone frozen. We evaluate on WebShop, PinchBench, and Claw-Eval with Kimi-K2.5, GLM-5, and GPT-5.2. SkillAdaptor improves over no-skill and skill-adaptation baselines on all three suites, with the largest single-metric improvements of +1.5 points on PinchBench Avg Score%, +1.8 on Claw-Eval Avg Score, and +1.7 on WebShop success rate. These results indicate that step-level attribution supports more stable and auditable training-free skill maintenance\footnote{The code will be released at https://github.com/zjunlp/SkillAdaptor.}.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：大型语言模型（LLM）智能体在执行长时程交互任务时，常依赖可复用的外部技能（skills）来指导行为。现有无训练（training-free）的技能自适应方法通常基于完整轨迹或会话级反馈来更新技能，这导致**故障归因粗糙**——一条失败轨迹可能包含许多正确步骤，最终失败可能仅由少数几个早期错误引起，但整个轨迹被用于调整技能，从而产生不稳定或过于宽泛的修订。
- **动机**：需要一种更精确的归因机制，将技能更新局限在真正导致失败的具体步骤和相关技能上，以提高适应效率和稳定性。
- **整体含义**：本文提出 **SkillAdaptor**，一个**步级（step-level）**的无训练技能自适应框架，通过显式定位首个可归责的故障步、关联责任技能、并执行目标更新，实现了比轨迹级更新更稳定且可审计的技能维护。

## 2. 方法论：核心思想、关键技术细节、流程

### 核心思想
- 将适应单元从**完整轨迹**缩小到**具体步骤**：识别首个关键故障步骤，分析其导致失败的原因，然后只修正或补充与该步骤直接相关的技能。

### 关键技术细节
- **技能表示**：采用OpenClaw风格的`SKILL.md`格式，每个技能包含标题（title）、适用条件（when_to_apply）、行为原则（principle）和程序步骤（procedure）等结构化字段。
- **技能检索与注入**：使用Qwen3-Embedding-8B进行稠密检索，先基于余弦相似度筛选（阈值0.45），再对Top-10候选技能由基座LLM进行重排，最终将选中技能注入智能体的提示中。
- **技能自适应三阶段**：
  1. **Attribution（归因）**：
     - **Localizer**：从失败轨迹中找出首个可操作的故障步`t*`，并输出故障描述和改进建议`π`。
     - **Linker**：将故障责任分配给候选技能集合，输出加权嫌疑集`{(sj, wj)}`，并预测适应动作`â`（REVISE 或 GENERATE）。
     - 如果现有技能被误用或误导，则复审；如果现有技能不足以覆盖该场景，则生成新技能。
  2. **Modification（修改）**：
     - 若`â=REVISE`，修改嫌疑度最高的技能并替换；若`â=GENERATE`，基于上下文生成新技能并追加到集合中。
     - 生成新技能时，通过语义相似度阈值（θdup=0.95）去重，防止冗余。
  3. **Qualification（资格验证）**：
     - 重新执行任务，比较更新后的技能集合K+与原始K的性能差异Δ。仅当Δ≥0时接受更新，否则丢弃修改。
     - 这一门控机制阻止了有害或不稳定的技能进入集合，保证了长期适应的稳定性。

### 流程（文字描述）
1. **初始技能构建**：基座LLM无技能地执行任务集，从成功轨迹中提取初始技能集合K0。
2. 对于后续每个任务，从当前K中检索相关技能注入，执行任务得到轨迹τ和结果r。
3. 若失败，进入适应阶段：
   - Localizer定位故障步t*；
   - Linker关联负责技能并预测动作类型；
   - Modifier执行修订或生成；
   - Qualifier通过再执行验证更新有效性。
4. 迭代最多10轮，若连续3轮无变化则提前终止。

### 公式
- 优化目标：`max_K E_{q∼Q}[success(Run(q, K))]`，即通过技能集合K最大化期望成功率。

## 7. 优点

- **精确归因**：将失败定位到具体步骤和相关技能，更新更高效、噪声更少。

- **Qualifier门控**：通过重新执行验证，阻止有害更新，确保性能不下降。
- **去重机制**：新技能生成时通过语义相似度过滤冗余。
