## 摘要
终身学习对于在动态交互环境中运行的大型语言模型（LLM）智能体至关重要。然而，现有的用于长周期任务的终身学习智能体通常在推理时依赖于离散技能或过去经验的检索，且参数静态不变，这阻止了它们像人类学习者一样持续内化测试时的反馈。为弥补这一差距，我们提出了技能增强型测试时协同进化（LifeSkill），这是一种面向在线终身学习智能体的两阶段强化学习框架。具体地，我们设计了验证器引导的技能学习，通过根据多个技能条件策略滚动的平均验证器成功率为候选技能提供奖励，从而解决技能提取缺乏直接监督的问题，鼓励模型生成有助于解决任务的技能，而不仅仅是文本上看似合理的技能。此外，我们引入了在线技能内化，通过将技能条件轨迹转化为奖励信号，在测试时交互中持续改进策略模型。这使得智能体能够直接将其推理能力内化到其参数中，避免了经验检索的上下文膨胀。在LifelongAgentBench上的实验表明，与现有的终身智能体基线相比，LifeSkill将平均性能提高了7个绝对值。

## Abstract
Lifelong learning is essential for Large Language Model (LLM) agents operating in dynamic, interactive environments. However, existing lifelong learning agents for long-horizon tasks typically depend on discrete skill or past experiences retrieval with static parameters during inference, which prevents them from continuously internalizing test-time feedback like human learners. To bridge this gap, we propose Skill-enhanced Test-Time Co-Evolution (\texttt{LifeSkill}), a two-stage reinforcement learning framework for Online Lifelong Learning Agents. Specifically, we design Verifier-Guided Skill Learning that addresses the lack of direct supervision for skill extraction by rewarding candidate skills according to the average verifier success of multiple skill-conditioned policy rollouts, encouraging the model to generate skills that are useful for solving tasks rather than merely plausible in text. Furthermore, we introduce Online Skill Internalization, which continuously improves the policy model during test-time interaction by transforming skill-conditioned trajectories into reward signals. This enables the agent to directly internalize reasoning capabilities into its parameters, avoiding the context bloat of experience retrieval. Experiments on LifelongAgentBench show that LifeSkill improves average performance by 7 absolute points by comparing with existing lifelong agent baselines.

# 论文分析：LifeSkill —— 面向在线终身学习智能体的技能增强型测试时协同进化框架

### 1. 核心问题与研究动机

- **核心问题**：现有的大语言模型（LLM）智能体在动态、交互式的环境中进行终身学习时，面临三大限制：
    1.  **参数静态**：大多数智能体在测试（部署）时保持模型参数不变，仅依赖外部记忆（如检索过往经验）来提升性能，无法像人类一样在交互中实现真正的持续学习。
    2.  **技能提取缺乏监督**：尽管已有工作能从交互中总结轨迹或进行反思，但对于如何从交互反馈中提取可复用的“技能”（Skill），缺乏可靠且基于执行结果的监督信号。现有方法或依赖主观的LLM评判，或只是启发式总结，无法保证技能的实用价值。
    3.  **知识内化困难**：获取的知识通常以离散的外部文本形式存在，使得模型难以将其内化为自身的参数知识进行组合和泛化，导致检索出的经验无法转化为持久的模型能力。
- **研究动机**：为了解决上述问题，使LLM智能体能够在测试时通过交互持续获取并吸收新知识，从而真正实现能力的增长。论文提出一种新的框架，让智能体将测试时的反馈转化为持久的参数化能力增长，而非依赖不断膨胀的上下文窗口。

### 2. 方法论：LifeSkill 框架

- **核心思想**：提出一个两阶段的强化学习（RL）框架，包含**验证器引导的技能学习（VGSL）** 和**在线技能内化（OSI）**，形成一个测试时协同进化环路。
- **整体架构**：维护两个模型：
    - **策略模型 $\pi_θ$**：用于执行任务。
    - **技能提取模型 $\pi_ϕ$**：用于从失败的交互中提炼可复用的技能。
- **算法流程（以文本说明）**：
    1.  **初始尝试**：策略模型对当前任务 `q` 进行首次尝试 `τ(0)`，验证器 `V` 给出奖励 `r(0)`。
    2.  **失败触发（若`r(0)=0`）**：
        - **技能提取**：技能提取模型根据任务和失败轨迹 `(q, τ(0))`，生成 `Ks` 个候选技能 `si`。
        - **技能评估与优化（VGSL阶段）**：对每个候选技能 `si`，策略模型进行 `Kτ` 次条件滚动（skill-conditioned rollouts），得到 `Kτ` 条轨迹和对应的验证器奖励。通过计算每个技能的平均成功率 (`R_i`) 来衡量其效用。论文使用 DAPO (一种强化学习算法) 目标函数，根据基于验证器奖励计算出的优势值 (`Â_i`) 来更新技能提取模型，奖励那些能提高后续策略执行成功率的技能。**关键在于，技能提取模型的优化信号不再来自LLM的主观评判，而是来自于下游任务的实际执行结果（验证器）。**
    3.  **技能内化（OSI阶段）**：
        - 收集窗口 `t` 内所有成功技能引导的轨迹 `(q, s, τ, r=1)`。
        - 移除轨迹中的显式技能文本 `s`，仅保留原始任务-输出对 `(q, τ)`。
        - 在当前策略模型下，重新计算 `(q, τ)` 的概率 `log π_θ(τ | q)`。
        - 使用奖励加权的策略优化方法更新策略模型 `π_θ`，让策略模型学习如何在没有外部技能提示的情况下，也能自主产生成功的行为。**核心在于，有用的行为被直接吸收进模型参数，而非作为外部记忆存储。**
- **核心技术细节**：
    - **VGSL**：解决了技能提取缺乏直接监督的难题，通过执行结果（平均验证器成功率）来引导技能生成，确保技能的实用性。
    - **OSI**：解决了知识内化问题，将成功轨迹转化为奖励信号直接更新策略模型，有效避免了外部记忆检索带来的“上下文膨胀”。
    - **协同进化**：VGSL改进了技能质量，产生更好的探索方向；OSI则将有效探索结果内化，提升策略基础能力，两者互相促进。
