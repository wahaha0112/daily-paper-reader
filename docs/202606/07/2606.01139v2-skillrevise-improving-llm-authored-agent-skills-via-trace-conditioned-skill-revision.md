## 摘要
智能体技能是使LLM智能体能够执行工作流、验证约束并从失败中恢复的程序性工件。现有的自进化方法利用累积的轨迹来优化技能。然而，它们在冷启动设置中表现不佳，因为只有初始的不完美技能可用。因此，技能构建默认依赖于专家编写或一次性LLM生成。专家编写的技能成本高昂，且可能与LLM智能体实际执行任务的方式不一致，而一次性生成的技能可能在语法上合理但行为上薄弱。为弥补这一差距，我们提出SkillRevise，一个基于执行的框架，旨在迭代优化这些初始技能。SkillRevise从执行证据中诊断技能缺陷，从通用记忆中检索相关修复原则，并应用基于执行的编辑。通过重新执行候选技能并度量经验效用，它系统地保留最优技能版本。在三个基准测试和五个LLM上的评估显示，SkillRevise显著优于一次性基线，将SkillsBench上基础智能体的成功率从36.05%提升至61.63%。此外，修订后的技能展现出强大的跨模型迁移能力，捕获了超越特定模型工件的通用程序性知识。

## Abstract
Agent skills are procedural artifacts that enable LLM agents to execute workflows, verify constraints, and recover from failures. Existing self-evolving methods refine skills using accumulated trajectories. However, they struggle in cold-start settings, where only an initial, imperfect skill is available. Consequently, skill construction defaults to expert authoring or one-shot LLM generation. Expert-authored skills are costly and may not align with how LLM agents actually execute tasks, while one-shot generated skills can be syntactically well formed yet behaviorally weak. To bridge this gap, we propose SkillRevise, an execution-grounded framework designed to iteratively refine these initial skills. SkillRevise diagnoses skill defects from execution evidence, retrieves relevant repair principles from a general memory, and applies execution-anchored edits. By re-executing candidates and measuring empirical utility, it systematically retains the optimal skill version. Evaluated across three benchmarks and five LLMs, SkillRevise substantially outperforms one-shot baselines, improving the base agent's success rate on SkillsBench from 36.05% to 61.63%. Furthermore, the revised skills exhibit strong cross-model transferability, capturing generalized procedural knowledge over model-specific artifacts.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：LLM 智能体在复杂、验证器驱动的环境中需要执行多步工作流、验证约束和从失败中恢复。Agent 技能（skills）作为可复用的程序性知识，能弥补工具和提示的不足。然而，现有技能获取方法存在缺陷：
    - 专家编写成本高，且可能不符合 LLM 实际执行方式；
    - 一次性 LLM 生成的技能语法正确但行为薄弱；
    - 自进化方法（如 SkillX、SkillRL）依赖大量累积的轨迹，在冷启动场景（仅有初始不完美技能）下表现不佳。
- **核心问题**：如何在冷启动条件下，通过有限的执行反馈，迭代改进初始的低质量技能，使其变得可靠且可迁移。
- **整体意义**：提出一种执行驱动的技能修订范式，将技能视为可测试、可调试的程序性工件，而非静态建议，从而降低专家编写成本并提升自动化技能构建的质量。

## 2. 方法论（核心思想与技术细节）

### 核心思想
- **任务特定/通用分解**：将修订过程分解为任务特定的执行证据诊断（Diagnosis）和通用可重用的修复原则（Principle Memory）。通过耦合二者，生成执行锚定（execution-anchored）的编辑，并在有限预算内通过重执行和效用门控保留最佳技能版本。

### 关键技术细节
1. **诊断（Diagnosis）**：对第 i 次修订，诊断表示为三元组 \( D_i = (V_i, A_i, K_i) \)：
   - \( V_i \)：验证规范（输出路径、格式、断言等）；
   - \( A_i \)：失败归因（失败检查、观察行为、可能原因、缺陷标签）；
   - \( K_i \)：保留约束（已通过检查及负责该行为的选择）。
2. **原则记忆（Principle Memory）**：存储通用修复原则，每个原则包含：触发条件、缺陷标签、修复规则、动作模板、验证模板、迁移约束等。初始包含 7 个原则。
3. **修订算子（Revision Operator）**：给定当前技能 \( S_i \)、诊断 \( D_i \) 和绑定原则 \( P_i \)，生成候选修订技能 \( \hat{S}_{i+1} \) 和修订轨迹 \( z_i \)。执行锚点（execution anchor）指定编辑如何改变执行器行为。
4. **有界修订回合（Bounded Revision Episode）**：在预算 B（默认 3）内迭代：
   - 执行当前技能，产生轨迹、验证反馈、评分和成本；
   - 若存在技能级缺陷，则从原则记忆中检索 top-m 候选原则，混合稀疏与稠密检索，加权倒数秩融合排序；
   - 绑定原则后调用修订算子生成候选；
   - 重执行候选，加入观察集；
   - **效用门控选择**：从观察集中选取效用函数最大的技能作为最终输出。效用函数综合考虑成功率、效率、迁移性和干扰成本，效率奖励仅在成功时生效。
