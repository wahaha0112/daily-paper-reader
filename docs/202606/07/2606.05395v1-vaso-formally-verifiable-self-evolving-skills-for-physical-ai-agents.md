## 摘要
可重用机器人技能正成为具身智能体将开放式指令转化为长期物理行为的基本单元。我们认为，虽然基础模型大幅降低了创建这些技能的成本，但信任它们的成本并未降低。现有的技能进化循环通过执行反馈、单元测试、环境奖励或大语言模型自我批评来精炼技能，但这些信号仅提供痕迹级证据：它们表明技能在采样执行中有效，而非技能引发的计划在未经测试的条件下满足时间安全契约。我们提出VASO，一个用于大语言模型生成机器人技能契约的验证引导自进化框架。在VASO中，每个技能被表示为具有两个耦合接口的语义契约：形式接口将机器人状态、观测和控制命令与用于模型检验的逻辑命题对齐，规划器接口则引导可执行行为生成。模型检验器首先过滤逻辑不一致的技能契约，然后针对全局和局部时间规范验证技能引发的计划。当验证失败时，VASO将反例轨迹转化为文本梯度，用于更新可重用技能契约，同时保持基础模型权重冻结。在Clearpath Jackal和PX4四旋翼任务上，VASO在少于100个优化样本下达到97.2%的形式规范合规率，优于执行反馈、提示优化和微调基线。据我们所知，VASO是首个将形式验证与面向物理AI智能体的自进化大语言模型技能闭环的框架：形式反例成为可重用机器人技能契约的优化反馈，而不仅仅是验证一次性计划、调整规划器提示或微调模型权重。

## Abstract
Reusable robot skills are becoming the basic units through which embodied agents turn open-ended instructions into long-horizon physical behavior. We argue that, while foundation models have collapsed the cost of creating these skills, the cost of trusting them has not. Existing skill-evolution loops refine skills through execution feedback, unit tests, environment reward, or LLM self-critique, but these signals provide only trace-level evidence: they show that a skill worked on sampled executions, not that skill-induced plans satisfy temporal safety contracts under untested conditions. We introduce VASO, a framework for verification-guided self-evolution of LLM-generated robot skill contracts. In VASO, each skill is represented as a semantic contract with two coupled interfaces: a formal interface that aligns robot states, observations, and control commands with logical propositions for model checking, and a planner-facing interface that guides executable behavior generation. A model checker first filters logically inconsistent skill contracts, then verifies plans induced by the skill against global and local temporal specifications. When verification fails, VASO translates the counterexample trace into a textual gradient that updates the reusable skill contract while keeping foundation-model weights frozen. On Clearpath Jackal and PX4 quadcopter tasks, VASO reaches 97.2% formal-specification compliance using fewer than 100 optimization samples, outperforming execution-feedback, prompt-optimization, and fine-tuning baselines. To our knowledge, VASO is the first framework that closes the loop between formal verification and self-evolving LLM-generated skills for physical AI agents: formal counterexamples become optimization feedback for reusable robot skill contracts, rather than merely verifying one-off plans, tuning planner prompts, or fine-tuning model weights.

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：当前机器人技能（skill）的创建成本因基础模型（如LLM）而大幅降低，但技能的**可信性保障成本**并未降低。现有技能的自我进化循环（如执行反馈、单元测试、环境奖励、LLM自我批评）仅提供**痕迹级证据**，即只能在已观测的样本执行上证明技能有效，无法保证在未测试条件下技能生成的计划满足**时态安全契约**（temporal safety contracts）。
- **整体含义**：对于物理AI智能体（如地面机器人、四旋翼无人机），安全瓶颈不再是“如何创建更多技能”，而是“如何使生成的技能以可检查、可重用、可验证的方式改进”。VASO首次将**形式化验证**（model checking）闭环融入技能自进化过程，使形式反例成为优化信号，直接改进可重用的技能契约，而非仅验证一次性计划或微调模型参数。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：引入一种**可验证的自进化技能表示**，每个技能表示为**语义契约**（semantic contract），包含两个耦合接口：
  - **形式接口**：将机器人状态、观测和控制命令与用于模型检验的逻辑命题对齐（通过命题对齐标签函数 \(L_{sk}\)）。
  - **规划器接口**：以文本计划模板（\(C^{ps}_{sk}\)）形式引导LLM规划器生成可执行行为。
- **关键技术细节**：
  - **技能定义**：技能 \(sk = (G, \psi_{sk}, C_{sk})\)，其中 \(G\) 为全局LTL规范集，\(\psi_{sk}\) 为局部规则，\(C_{sk} = (L_{sk}, C^{ps}_{sk})\) 为语义契约。
  - **两级验证**：
    1. **技能级验证**：检查局部规则 \(\psi_{sk}\) 与全局规范 \(G\) 是否逻辑一致（通过通用转移系统上的模型检验证明存在性）。若不一致，则重新查询基础模型 \(F_{skill}\) 修正。
    2. **计划级验证**：将规划器生成的计划 \(\pi\) 编译为自动机 \(A_\pi\)，利用命题对齐标签函数 \(L_{sk}\) 生成命题轨迹，检验 \(A_\pi \models G \land \psi_{sk}\)。
  - **语义契约优化**：验证失败时，模型检验器返回违反规范的反例轨迹。VASO将反例转化为**文本梯度**（textual gradient），例如：“违反规范 G(person_observed -> X stop)”。该文本梯度作为自然语言反馈输入基础模型，在冻结权重条件下迭代更新技能契约。数学上可以理解为一种**文本梯度下降**过程：
    - 前向：\(C^{(k)}_{sk} \rightarrow \pi^{(k)} \rightarrow A_{\pi^{(k)}}\)
    - 反向：\(A_{\pi^{(k)}} \rightarrow g^{(k)} \rightarrow C^{(k+1)}_{sk}\)

- **验证反馈能有效提升技能质量**：优化后的技能达到平均**97.2%** 规范合规率（安全分数），初始技能仅约89%。

- **优化技能可泛化到未见提示**：在未见任务提示上，VASO仍保持92–100%安全分数和80–96%任务完成率。
- **自动命题对齐实用**：自动生成的标签函数与手工标注性能相当（96.8% vs. 97.2%），消除了对领域专家手动定义的需求。

## 7. 优点
- **创新性**：首次将形式化验证闭环融入LLM生成技能的自我进化，使反例成为可重用技能契约的优化反馈。
- **结构化技能表示**：同时服务于模型检验和LLM规划的双接口设计，既保持可解释性又支持验证。
- **两级验证**：在技能级提前过滤不一致规范，避免无效优化；计划级精确定位违规行为。
- **效率高**：无需微调模型参数，训练样本少（<100），时间短（<20分钟/技能）。
- **实用性强**：自动命题对齐功能降低了应用门槛；优化后的技能可泛化到同任务族的新提示。

## 8. 不足与局限
- **命题对齐的可靠性**：自动生成的标签函数 \(L_{sk}\) 可能包含抽象错误，如PX4速度计算忽略垂直分量导致虚假验证通过。尽管实验显示这种误差对最终安全分数影响不足1%，但在安全关键场景下可能构成风险。
- **验证范围受限**：当前框架仅验证**顺序非并发**执行，不处理多个技能的重叠或交织（如并发技能调用、资源共享）。
- **未提及不确定性量化**：命题对齐缺乏置信度估计，无法为验证结果提供概率保证。
- **可扩展性待验证**：仅测试了地面和空中两种机器人，更大规模、更复杂的技能库或异构多智能体场景未评估。
- **依赖模型能力**：技能生成和优化效果受限于底层基础模型（GPT-5-nano）的推理和遵循指令能力。
