## 摘要
技能文档是指导大型语言模型（LLM）智能体的结构化自然语言指令，对于现代智能体框架至关重要，然而LLM难以编写实际有效的技能。在SkillsBench上，人类编写的技能将通过率提高了16.2个百分点，而LLM编写的技能没有带来可衡量的提升。我们引入了SkillAxe，一个完全无监督的框架，使LLM能够迭代地诊断和精炼自身的技能。SkillAxe将技能质量分解为四个可解释的维度（质量影响、触发精度、带故障归因的指令遵从性以及解决方案路径覆盖），生成结构化的改进简报，无需真实标签、测试套件或环境奖励。在SkillsBench上，SkillAxe在未改进的LLM技能基础上将通过率相对提高了28%，并缩小了与人类编写技能差距的47%至67%。我们验证了该方法作为连续改进引擎在SpreadsheetBench上的实际效果，其中SkillAxe构建的技能库从过去的智能体轨迹中学习，仅使用22个技能就将通过率从16.0%提高到52.0%。

## Abstract
Skill documents, structured natural-language instructions that guide Large Language Model (LLM) agents, are critical to modern agent frameworks, yet LLMs struggle to write skills that actually work. On SkillsBench, human-authored skills improve pass rates by 16.2 percentage points, while LLM-authored skills provide no measurable gain. We introduce SkillAxe, a fully unsupervised framework that enables LLMs to iteratively diagnose and refine their own skills. SkillAxe decomposes skill quality into four interpretable dimensions (quality impact, trigger precision, instruction compliance with fault attribution, and solution-path coverage), producing structured improvement briefs that require no ground-truth labels, test suites, or environment rewards. On SkillsBench, SkillAxe improves pass rates by 28\% relative over unimproved LLM skills and closes 47--67\% of the gap to human-authored skills. We validate the approach as a continuous improvement engine in the wild on SpreadsheetBench, where a SkillAxe-built skill library learns from past agent trajectories and raises pass rate from 16.0\% to 52.0\% using only 22 skills.

# 论文总结：SkillAxe

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：LLM 能自动编写技能文档（skill documents）——即用于指导智能体执行复杂任务的结构化自然语言指令——但 LLM 自产的技能在实际任务中几乎无效。在 SkillsBench 基准上，人类编写的技能可提升通过率 16.2 个百分点，而 LLM 编写的技能 **未带来任何可衡量的提升**，尽管语法流畅、表面合理。
- **整体含义**：当前技能工程缺乏**可操作的诊断反馈**。现有评估仅提供粗粒度的任务级通过/失败信号，无法定位技能失败的具体原因（如触发错误、指令模糊、智能体未遵守等）。这导致技能改进依赖人工试错，阻碍了自动化、可扩展的智能体持续提升。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：提出 **SkillAxe**，一个**完全无监督**的评估引导自我精炼框架，将技能质量分解为四个可解释维度，通过对比智能体**有技能**和**无技能**时的行为差异，自动生成结构化改进简报。
- **关键技术细节**：
  1. **质量影响（Quality Impact）**：通过配对比较（带技能 vs 不带技能的响应），用 LLM 判断偏好方向和改善幅度（得分在 [-1, 1]），区分局部回归与灾难性失败。
  2. **触发精度（Trigger Precision）**：利用依赖解析从技能描述中提取正触发短语和负触发短语，计算三个几何指标——覆盖广度、负特异性、边界清晰度——识别触发过窄、排斥不足或边界模糊的问题。上下文感知嵌入用于区分同一短语在不同语境下的含义。
  3. **指令遵从性与故障归因（Instruction Compliance with Fault Attribution）**：将技能分解为可评估的规则（权重 1-3），评价每个规则的**相关性**、**遵循度**、**规则质量**和**技能故障**，计算原始遵循得分和故障调整后的技能信用分。关键创新：分离智能体执行错误与技能本身缺陷，避免错误地“修正”正确规则。
  4. **解决方案路径覆盖（Solution-Path Coverage）**：枚举多种可能的解决方案路径，测量技能片段与各路径嵌入的余弦相似度最大值，判断技能是否支持智能体可能采取的不同策略，避免技能过于狭窄。
- **流程**：Phase 1 对比执行 → Phase 2 计算四维诊断 → Phase 3 LLM 根据改进简报重写技能 → Phase 4 迭代至收敛。

## 3. 实验设计

- **数据集与场景**：
  - **SkillsBench**：89 个任务（实际使用 77 个），191 个技能，688 次智能体运行；覆盖软件工程、数据科学、科学计算等。用于评估**任务特定技能改进**（给定任务指令改进对应技能）。
  - **SpreadsheetBench**：912 个真实电子表格操作任务，划分为 200 训练 / 50 测试任务（另保留 200 测试集）。用于评估**持续库改进**（从过去轨迹中构建和精炼共享技能库）。
- **智能体骨干**：Claude Opus 4.5（SkillsBench 和 SpreadsheetBench 均使用）。
- **对比方法**：
  - **No-skill**：无技能文档的裸智能体。
  - **LLM-self**：由 LLM 直接生成的未改进技能（SkillsBench 用 SkillsBench 提示生成；SpreadsheetBench 用同一生成提示构建 69 个技能）。
  - **SkillAxe**：经 SkillAxe 迭代改进的 LLM 技能（SkillsBench 中一次迭代；SpreadsheetBench 中构建 22 个技能）。
  - **Human**：人工编写的参考技能（仅 SkillsBench）。
- **评估方式**：
  - SkillsBench：采用 Terminal-Bench Method D 评分（每个任务 k=2 次运行，取均值）以及两种验证器——原生测试套件（保守下限）和公平评分器（LLM 判断，不接触测试用例）。
  - SpreadsheetBench：原生电子表格验证器（单元格级对比），并预先通过 Excel COM 自动化重新计算以修正缓存值问题。

## 6. 主要结论与发现

- **SkillsBench 结果**：
  - SkillAxe 将 LLM 自产技能的通过率从 32.5% 提高到 41.6%（相对提升 28%），缩小了与人类技能差距的 47–67%。
  - 层次分解显示，**全部增益来自覆盖率（从 46.7% 到 72.7%）而非回答质量**（正确率均为 57.1%），表明技能主要提供执行知识（如库使用、格式处理），防止崩溃而非提升答案质量。
- **SpreadsheetBench 结果**：
  - SkillAxe 构建的 22 个技能库将通过率从 16.0% 提升至 52.0%，与 69 个技能的未改进库持平，但技能数量减少 68%，激活率更高（35.8% vs 20.0%）。
  - 触发分析显示 SkillAxe 描述比人类技能具有 **3 倍更宽的判别边界**，表明路由质量更好。
- **核心发现**：技能的主要价值在于**执行可靠性**而非答案准确性；SkillAxe 的故障归因机制能有效区分技能缺陷与智能体执行错误，避免退化有用规则。

## 7. 优点

- **完全无监督**：无需真实标签、测试套件或环境奖励，仅依赖任务指令和智能体输出，适用范围广。
- **可解释的四维诊断**：质量影响、触发精度、指令遵从性（带归因）、路径覆盖，每个维度定位不同失败模式，生成结构化改进建议。
- **分离技能缺陷与执行错误**：通过故障归因信用评分，避免因智能体执行不佳而错误“修复”正确的技能规则。
- **高效压缩**：在 SpreadsheetBench 上以 68% 更少的技能达到相同性能，降低 token 成本和延迟。
- **持续改进**：支持从历史轨迹中学习和迭代，可作为生产环境中技能库的自动 flywheel。

## 8. 不足与局限

- **无法检测结构错位**：技能自身可能内部一致但策略根本错误，规则级改进无法发现。
- **未建模技能间交互**：多个技能同时激活时可能冲突，但本框架独立评估每个技能。
- **依赖 LLM 判断**：合规评估和公平评分均依赖 LLM 作为评判器，可能存在位置偏差、校准偏差等。
- **改进迭代次数有限**：SkillsBench 仅进行一轮迭代，人类技能与 SkillAxe 的剩余差距可能需多轮循环及更强的在线执行反馈。
- **SpreadsheetBench 单次分割**：仅使用一次随机划分，缺乏多次交叉验证的稳定性报告。
- **k=2 次运行导致高方差**：95% 置信区间宽达 ±8–10pp，结论的统计显著性有待更多运行验证。
- **未测试不同 LLM 骨干**：仅使用 Claude Opus 4.5，未评估对其他模型（如 GPT-4）的泛化性。
