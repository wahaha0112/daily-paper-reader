## 摘要
大型语言模型智能体越来越依赖技能：可重用的过程化文档，编码工作流程、工具使用、实现模式、验证检查和领域规则。技能重写通常被视为提示压缩，但较短的技能可能通过移除防止探索、调试和恢复的稀疏操作锚点而使智能体更昂贵。我们通过这一经济视角研究技能重写。我们的受控框架剖析技能结构，使用信息保留策略重写技能，并在固定任务指令、环境和验证器下评估重写结果。在SkillsBench上的实验揭示了不同策略间明显的质量-成本权衡：API/代码锚定、工作流守护、规则/公式锚定对不同任务族有利，没有普遍占优的模板。在主要留出评估中，学习到的策略将总成本降低7.0%，下游智能体令牌成本降低6.0%；在冻结的跨模型迁移中，相应的降低平均为14.7%和13.7%，同时验证器质量得以保持。这些结果将技能设计定位为成本感知的操作知识工程，而非提示压缩。资源：\href{https://github.com/1Reminding/Skill_EE}{SkillEE}。

## Abstract
Large language model agents increasingly rely on skills: reusable procedural documents encoding workflows, tool use, implementation patterns, validation checks, and domain rules. Skill rewriting is often treated as prompt compression, but shorter skills can make agents more expensive by removing sparse operational anchors that prevent exploration, debugging, and recovery. We study skill rewriting through this economic lens. Our controlled framework profiles skill structure, rewrites skills using information-preservation strategies, and evaluates the rewrites under fixed task instructions, environments, and verifiers. Experiments on SkillsBench reveal distinct quality--cost trade-offs across strategies: API/code anchoring, workflow guarding, and rule/formula anchoring benefit different task families, with no universally dominant template. In the main held-out evaluation, the learned policy reduces total cost by 7.0\% and downstream agent-token cost by 6.0\%; in frozen cross-model transfer, the corresponding reductions average 14.7\% and 13.7\%, while verifier quality is preserved. These results position skill design as cost-aware operational knowledge engineering rather than prompt compression. Resources: \href{https://github.com/1Reminding/Skill_EE}{SkillEE}.

# 论文总结：What Should a Skill Remember? Quality-Cost Trade-offs in Cost-Aware Skill Rewriting for Language Model Agents

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：大型语言模型（LLM）智能体越来越多地依赖“技能”（Skills）——可重用的过程化文档，包含工作流、工具调用、代码模式、验证规则和领域知识。现有研究往往将技能重写简单视为提示压缩（prompt compression），即缩短文本以降低直接令牌成本。
- **核心矛盾**：缩短技能可能移除关键的“操作锚点”（operational anchors，如API签名、验证阈值、恢复规则等），导致智能体在执行过程中需要更多探索、调试和修复，反而增加下游执行成本（agent-token cost）。
- **研究目标**：从经济视角重新定义技能重写问题——技能重写不是单纯的压缩，而是**成本感知的知识保留**（cost-aware knowledge preservation），需要根据任务和技能结构选择保留哪些操作锚点，从而在保持任务质量的同时最小化总执行成本（直接技能令牌+下游智能体令牌）。

## 2. 方法论

### 2.1 核心思想
- 技能重写看作一个受控的信息保留过程：保留对任务执行至关重要的操作锚点，同时移除其他低价值文本。
- 不同任务和技能结构需要不同的保留策略，不存在通用的最佳模板。因此学习一个**任务条件化策略选择器**（task-conditioned strategy selector），从一组预定义的保留策略中为每个任务选择最经济的策略。

### 2.2 关键技术细节

#### （a）技能剖析（Skill Profiling）
- 对每个任务-技能对计算结构画像 \(\phi_\tau\)，包括：技能个数、总令牌数、代码令牌比率、API/工具使用标记、验证规则、公式、领域标签、主导技能原型等。

#### （b）重写策略家族
论文定义了四种信息保留策略（见表1）：

| 策略 | 保留的锚点 | 适用场景 |
|------|-----------|----------|
| 源码紧凑（Source-native compacting） | 原始结构、本地术语、作者组织 | 结构已含有效工作流的技能 |
| 工作流守护（Workflow guarding） | 有序步骤、验证检查、约束、陷阱 | 易遗漏检查或过程漂移的任务 |
| API/代码锚定（API/code anchoring） | 导入、API调用、对象构造、命令、代码片段 | 代码或工具密集型技能 |
| 规则/公式锚定（Rule/formula anchoring） | 定义、公式、阈值、模式、约定 | 科学计算、优化、规则主导的任务 |

- 重写过程使用LLM辅助，通过特定提示模板生成重写版本，并进行后生成审计（包括令牌比率检查、代码术语覆盖率、代码块保留、缺失锚点修复等）。

#### （c）任务条件化策略学习
- 目标：学习一个策略选择器 \(\pi_\theta(\phi_\tau)\)，该选择器以任务-技能画像为上下文，选择能最大化经济效用 \(U^a_\tau\) 的策略。

- **经济效用**（公式7）：
  \[
  U^a_\tau = QR^a_\tau + \lambda_{\text{save}}(1 - \rho^a_\tau) - \lambda_{\text{over}} EO^a_\tau + \lambda_{\text{nld}} NLD^a_\tau
  \]
  其中：
  - \(QR^a_\tau\)：质量保留率（验证分数与原始技能分数之比）
  - \(\rho^a_\tau\)：总成本比率（总令牌成本与原始技能成本之比）
  - \(EO^a_\tau\)：下游执行超额惩罚（下游令牌成本超过基线部分）
  - \(NLD^a_\tau\)：近似无损红利（当质量损失可忽略且总成本节省时的奖励）

- **学习算法**：使用稀疏效用回归拟合一个动作条件效用模型 \(\hat{U}_\theta(\phi_\tau, a)\)，包含策略特定截距和特征权重，并施加L1惩罚。然后通过蒸馏得到一个小型决策列表作为冻结策略。

## 6. 论文的主要结论与发现

1. **固定重写策略展现互补的质量-成本权衡**：没有一种策略普遍最优。API/代码锚定在代码密集型任务中平衡较好；规则/公式锚定虽经济但损失通用质量；工作流守护缩短文档却增加下游执行成本。
2. **技能重写不能仅用令牌长度评估**：工作流守护将技能令牌降至58%，但下游代理令牌升至114%，总成本反而增加11%。
3. **学习到的任务条件化策略有效**：在主留出面板中，策略选择重写保持验证质量（QR=1.01），总成本降低7.0%，下游令牌成本降低6.0%。跨模型迁移中，对应降幅平均为14.7%和13.7%，且验证器质量保持或略有提升。
4. **策略偏好结构化**：API/代码锚定被长技能、高代码密度、有API/工具使用的任务偏好；规则/公式锚定用于科学计算和约束密集型任务；工作流守护仅当过程检查重要性超过下游成本增加时有用。
5. **消融表明关键组件**：锚点修复对质量影响最大（移除后质量下降）；近无损红利和超额惩罚对成本平衡至关重要。

## 8. 不足与局限

- **实验覆盖有限**：仅基于SkillsBench一个基准，未在更多真实世界环境（如Web导航、软件工程、机器人）中验证。任务族覆盖6类，但每个族内任务数量有限。

- **策略学习信号稀疏且昂贵**：每个任务-策略对需要一次完整代理执行，对大规模部署可能不实用。离线学习框架假设可用历史运行数据。
- **未评估动态技能更新**：实验假设技能在代理执行前固定，未考虑运行时动态检索或更新技能。
- **安全风险关注**：论文指出重写可能移除安全相关约束或“不可做”规则，虽然通过保留策略和审计缓解，但不应替代人工审查，尤其在高风险领域。
- **无多轮或持续学习场景**：仅评估单次执行，未考虑代理需要连续学习或适应技能环境。
